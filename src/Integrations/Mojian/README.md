# 墨笺应用模块包

[手写体工具与接入方法](https://github.com/LeoLi006/handwriting-tool/blob/main/integrations/leo/README.md) · [Leo](https://github.com/LeoLi006/leo-desktop)

在 Leo 的应用模块管理窗口导入 `mojian.leoapp.json`，按预览选择自己为墨笺启动脚本建立的 `.lnk`。这是数据包，不包含墨笺、Python、启动参数或个人路径。脚本自动接入与手动导入共用同一包标识，不需要同时操作。入口使用既有本机应用执行器；转换在墨笺独立窗口完成。
