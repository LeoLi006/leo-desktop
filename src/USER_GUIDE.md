## 安装与设置

从GitHub Release下载完整ZIP，解压后运行Install-Leo.cmd。升级选择原安装位置，先保存私有备份。不要将开发输出直接覆盖个人安装。

右键伙伴 → 设置：名字、大小、快捷键、开机启动、模块、API、迁移与运行检查。常规顶部可切换简体中文/英文并保存。电脑状态和邮件默认关闭，按需启用。语言只改变界面，不翻译个人内容、不改变语音识别或模型回复语言。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 单击 | 切换应用搜索，搜索打开时锁定伙伴位置 |
| 拖动 | 移动，接近显示器边缘松手吸附 |
| 悬停头部 | 展开并恢复功能按钮 |
| Esc | 关闭当前窗口或收起面板 |
| 右键 | 分组菜单：记录、应用媒体、组合、外观、设置 |

隐藏入口只改变按钮/菜单显示；停用才拒绝能力并停止其后台活动，不自动退出外部应用。

## 应用与文件

按名称、拼音和简称搜索，例如wx、weixin、vsc；右键应用设置别名。收藏可拖拽排序。两排候选每排七个，最近使用和匹配按当前设置展示。输入完整路径可打开文件或文件夹，支持空格、引号和环境变量。

搜索框左侧的网格图标搜索应用，文件夹图标同时搜索文件和文件夹（Ctrl+1 / Ctrl+2切换），每次打开默认应用。文件搜索按名称查找所选目录及子目录，结果混合显示文件与文件夹，初始为文档目录；点击“搜索目录”更换，也可直接粘贴完整路径。方向键选择、回车打开，点击“VS Code 新窗口”或按 Ctrl+Enter，用新窗口打开选中的文件或文件夹。未找到 VS Code 时可手动选择 Code.exe。搜索只在本机进行，不调用模型；跳过隐藏/系统目录和链接，最多扫描3秒或3万项、显示80个结果，到达上限会提示缩小目录。搜索目录和手动选择的 Code.exe 本次运行内保留。

方向键选择，Enter打开，Tab补全路径，Ctrl+L回到输入；Shift+F10打开候选菜单。拖入程序可添加模块，其他文件、文字和网址显示适用的动作面板。

设置 → 功能中的应用管理可指定程序、图标、启动参数、工作目录和管理员选项；图标库提供18种图标，也可用自己的图片。快捷栏支持排序和溢出菜单。路径修复需要确认，不凭空改路径。

## 清单、便签与剪贴板

清单提供日、周、日历及逾期视图；支持自然输入、重复/例外、右键操作、双击编辑、拖到日期改期、一键顺延和适用操作的撤销。添加前核对解析结果。提醒可稍后10分钟或1小时，设置免打扰时段；Leo关闭时不能承诺提醒。

速记快捷键可配置，回车保存、Esc取消。便签可搜索、置顶及转待办。搜索“剪贴板”打开历史/收藏；可停用监听并设置敏感内容保护。真实秘密仍需自行保护。

## 足球、音乐与媒体

足球窗口管理俱乐部和国家队关注，查看近期结果、未来赛程、球队比赛和积分榜，设置观赛网址，并将真实比赛加入清单。联网失败保留缓存，留意时间和过期提示。后台校时受数据源可用性影响。

QQ音乐定位为快速点一首歌：搜索后选择真实歌曲，未启动时先启动并等待。暂停、控制和歌词依赖客户端状态/配置。歌单请到QQ音乐操作，Leo不提供歌单同步。PotPlayer及媒体窗口控制已配置客户端或Windows媒体会话。

脚下工具栏的 Clash 图标用于打开 ClashDock，已运行时唤起窗口，未运行时启动；不再点击切换系统代理。首次可选择 ClashDock.exe，之后记住位置。其他明确的代理指令仍由 Clash 模块处理。停用模块不等于关闭代理。

## 电脑状态、火绒与邮件

电脑状态只读显示CPU、内存、网络汇总、系统盘空间及进程排序，提供任务管理器入口；没有结束进程或清理操作。可选高占用提醒：CPU90%或内存92%持续30秒、15分钟冷却。高占用不等于病毒。

火绒个人版只快速打开客户端，不扫描、不显示安全结论。邮件使用已有Foxmail/Thunderbird/经典Outlook或手动指定EXE/LNK；QQ/Gmail也可打开网页。校园邮箱在原客户端配置。Leo不接收邮箱密码、不拉邮件、不统计未读。

## 聊天、语音与组合

API设置填写自己的兼容服务、模型和Key；不要公开配置。明确命令优先本地，事实查询交给对应模块，复杂理解才调用模型。模型计划需按现有规则预览确认，不能凭空生成目标编号。

语音使用独立安装的SenseVoice本地模型。设置模型后测试麦克风权限；界面英文不代表英文识别自动配置。停止/关窗丢弃过期结果。组合是现有动作的顺序执行，可取消和核验失败步骤，不是任意脚本系统。

## 皮肤与配置

外观中可选五套皮肤、新建独立主题、导入球衣和队徽，调整色彩/明暗/圆角/透明度。清单话语每行一句，可删空关闭。规范与限制见[皮肤格式](SKIN_FORMAT.md)。使用方案切换先看差异；公开分享包不同于私有备份。

## 排查与反馈

先打开设置 → 运行检查，核对模块开关、路径、依赖和错误类型；“已安装”不等于“正在正常工作”。普通成功只进安静日志，报错和提醒才需要注意。错误重试前确认是否已经产生外部效果。

反馈提供版本/提交、Windows环境、操作步骤和脱敏截图。不要上传运行目录、Key、真实聊天/剪贴板或整份个人日志。

## 语音模型、迁移与用量

源码使用者可在仓库根目录运行以下现有脚本安装本地模型；首次需要网络，模型不进入Git。发布包用户先核对包内是否提供对应脚本和说明，不要假设仓库脚本在安装目录存在。

```powershell
./scripts/Install-VoiceModel.ps1
```

语音在本地转文字；若文字进入模型对话，文本会发送到自己配置的服务。Leo没有通用网页浏览工具；浏览器搜索与专门赛程来源不代表每次模型回复已联网核实。

配置迁移在设置 → 常规 → 配置迁移与恢复。导入前看摘要，保留原备份。迁移导出不同于公开分享：可能包含待办、网址、简称与程序路径，应当作私有文件；不包含API Key、聊天、剪贴板或语音模型，不上传GitHub。

用量页默认每日100次模型生成请求，0表示不限；失败/取消也可能已发请求并计数，模型列表读取不计入。Token只记录服务返回值，不猜费用；关闭不兼容的Token统计选项后仍可聊天。本地功能不受模型用量上限影响。

## AI 动态：新闻与论文／项目速览

- **入口**：单击 Leo 后，顶部新闻图标“AI 动态”；也可搜索“AI新闻 / 论文 / 全双工”，或从右键菜单的模块入口打开。图标溢出时在“更多”里。
- **速览**：保留标题和原文短导语，先列论文、再列 GitHub 项目，同类按日期倒序；可进一步只看论文或项目。GitHub 为近30天活跃、按总 Stars 筛选的相关仓库，不是每日增星榜。
- **新闻**：独立读取 Google News 聚合报道、量子位、OpenAI 和 Google DeepMind 的 RSS，显示媒体报道和官方发布，按发布时间排序。不会把 arXiv 摘要或 GitHub 条目冒充新闻；Google News 卡片经聚合页打开报道，其他来源打开原文。
- **中文标题**：新闻页点击“中文标题 · API”，使用已有中转站／模型配置翻译英文标题；仅发送公开标题，不发送摘要、聊天或剪贴板。每20条一批，每次最多60条／3次请求，计入现有 API 用量和上限，可能产生模型费用；不是免费离线翻译。已翻译标题会缓存，重复查看不再调用；“显示原文 / 显示中文”只切换显示。摘要仍保留原文，切换领域或关窗会取消在途翻译，已发送请求按实际计数。
- **专业领域**：左侧下拉列表提供24项选择，包含全部 AI、Agent、多智能体、全双工语音、ASR/TTS、大模型、推理、NLP、多模态、视觉、图像视频生成、机器人、强化学习、RAG、安全对齐、评测、训练、端侧压缩、系统芯片、AI4Science、医疗、推荐、图学习、隐私和产业政策。两个视图共用领域选择；换方向会按相应关键词／类别重新查询，不是只筛选旧 Agent 数据。来源数量和关键词匹配有局限，不能视为完整文献检索或全面新闻收录。
- **阅读和播报**：点击卡片直达原文；“朗读此条”或“播报当前列表”朗读原始标题和短导语（最多前5条），可随时停止，关窗自动停止。不录音、不需要SenseVoice、不自动翻译或生成结论。
- **缓存与网络**：打开窗口或切换方向时按需刷新，关键词文本框只在本地筛选已获取内容。各模式／领域独立缓存，来源失败保留本方向旧内容及原获取时间，不混用其他方向。正常缓存10分钟，同方向一分钟内不重复刷新；切换时取消过期请求，没有常驻新闻轮询。旧版缓存会在新查询后升级。
- **开关与费用**：设置 → 功能 → AI 动态；入口位置独立管理。纯桌宠方案停用此模块。获取动态、朗读及读取缓存不调用模型；只有手动翻译标题使用已配置的 API 与Key。不读取私人仓库、聊天或剪贴板，只缓存公开元数据和标题译文，不下载完整论文或仓库。

## 应用位置与文件打开方式

应用搜索结果的真实本机应用可右键“打开应用所在文件夹”，解析快捷方式目标并选中程序；没有普通程序目录的商店／网址／内部条目不显示此项。拖文件或文件夹到正常显示的 Leo 头、脸、身体，先选择打开方式；默认应用、资源管理器、可用的 VS Code 新窗口及单文件 PotPlayer 都复用现有动作入口。Windows 的“打开方式”提供系统候选；自定义应用／浏览程序属于手动指定，保留参数、工作目录和管理员选项，不声称文件类型兼容。多项会显示数量与完整路径；默认打开、VS Code 和定位支持全部项，其他方式明确限单项。成功回执仅表示已提交请求。详见[快速指南](QUICK_START.md#应用目录与拖放打开)。
