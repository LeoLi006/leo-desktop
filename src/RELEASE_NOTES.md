## v1.06.0 — 2026-11-07 · 文件快捷处理与按需集成

这次功能大更新汇总 v1.05.0 之后的改进，继续使用 1.x 版本兼容范围。提供完整 Windows x64 安装 ZIP、自带桌面运行时及 SHA-256 校验文件。

### 更方便地找文件与处理文件

- 应用搜索与文件/文件夹搜索可用图标切换；支持直接输入路径，以及用 VS Code 新窗口打开文件或目录。两种搜索模式保持同样大小，修正大小滑动条重绘。
- 真实本机应用右键可定位实际程序；快捷方式解析目标，不把开始菜单快捷方式目录当成程序位置。
- 拖到 Leo 头部、脸部或身体后，先选择动作，不立即执行。最多三个相关主要动作，其余打开方式、复制路径、定位、便签和待办保留在辅助区。
- 单 Markdown 文件可交给墨笺导入并进入预览/确认流程。需要另行准备支持导入接口的墨笺和依赖齐全的 Python；不代装。收到匹配回执才确认导入，**不会自动确认模板、生成、导出或覆盖原文**。目前一次一个 Markdown。
- VS Code 始终使用新窗口；PDF 可配置 SumatraPDF。打开能力复用应用模块的类型声明、程序路径、参数、工作目录和显式管理员选项；路径只存本地。类型匹配不是兼容保证，启动请求不代表文件已打开。

### 按需接入已有产品

- AI 资讯窗口区分新闻与论文/项目速览，按领域筛选；提供按需标题中文翻译和可选朗读。内容来自网络来源，不保证覆盖全部 AI 动态或每条都实时。
- 脚下统一搜索可切换 Edge、Gemini、DeepSeek、ChatGPT。网页 AI 填写/发送需要用户自行加载随包浏览器扩展并登录相应网站，不使用模型 API Key。网站改版、登录或安全验证可能需要人工处理。
- 原代理位置提供 ClashDock 快捷入口。ClashDock 是独立软件，需单独准备；本发布包不包含它，也不假称其已安装。未配置或不可用时简短提示，右键该按钮可指定路径。
- 可选软件、墨笺程序/脚本和模块不存在时，不应阻断其他入口。补齐配置读取失败、启动失败、超时、取消及失败后继续操作的定向检查。

### 安装、隐私与验证

完整解压后运行 `Install-Leo.cmd`；升级选择原来的 Leo 专用目录，沿用清单校验、备份及失败回退。原配置保留，第三方客户端、个人路径、API Key、聊天与剪贴板数据、语音模型不随包发布。中英文指南独立，见[快速操作指南](QUICK_START.md)。

相关证据包括 55 项打开能力检查、15 项 ClashDock 检查、此前 51 项拖放/入口检查，以及墨笺单文件接口与隔离真实 GUI 导入验证。本次发布另检查包清单、干净安装、自带运行时启动和更新回退；不把这些定向检查宣称为所有系统或长期负载的保证。

## v1.05.0 — 2026-10-22

本次将v1.00.0之后的主分支改进集中发布为Windows x64安装包，附SHA-256校验文件。

### 安装与兼容

完整解压，运行Install-Leo.cmd，更新时选择原安装目录；发布清单校验、更新前备份和回退沿用现有安装器。包内包含Windows桌面运行时，不含个人配置、Key、语音模型或第三方客户端。

### 最近变化

- `48df4ea`：可选只读电脑状态和现有邮件客户端入口，默认关闭；火绒仅快速打开。
- `874b78f`：比赛后台元数据按相关事项筛选、去重和分批，避免大缓存超过动作输入上限；聊天文字重排、18种图标及电脑状态布局改进。
- `6e4bca5`：聊天缩放/还原后合并布局和原生子窗口重绘，避免空闲循环刷新。
- `42fea41`：简体中文/英文界面、本地资源、设置入口、动态控件与用户内容保护。
- 文档归并为中英双文指南；安装包附本地说明，源码接口链接指向本版本标签。

### 此前主分支底座

统一执行、契约、入口贡献、限定宿主服务和后台活动归属；清单/足球/便签/媒体等主要能力迁移；有界模型计划和组合恢复；旧扩展兼容检查、更新回退、状态及分享隐私核验。详细边界见[架构](Architecture/README.md)及[路线图](ROADMAP.md)。

通知成功记录使用安静日志；错误和提醒保留必要反馈。修复搜索/右键设置间切换，并提供自定义队徽和清单话语。旧逐轮记录改由Git提交保存，不在当前说明重复累加测试数。

### 发布验证

发布包文件哈希、隐私与文档链接检查通过；隔离验证了干净安装、自带运行时启动、更新回退保留设置及首次启动界面。没有重跑无关业务全量测试。构建成功，但在线NuGet漏洞元数据检查受网络限制产生NU1900警告，不声称完成在线依赖漏洞审计。
