# Leo v1.00.0 · 桌面动作入口大版本

本次集中发布v0.50.0之后的本地更新：统一动作分发、应用模块与扩展、完整自定义皮肤、媒体控制，以及拖放与便签。已有设置、清单、模型与个人记录保留在原安装目录。

## 1. 统一动作与模块

- 聊天、语音识别结果、搜索框、自定义组合共用动作入口，明确口令在本地执行。
- 终端、Clash、QQ音乐、Edge、PotPlayer统一管理开关、程序路径及快捷图标。
- EXE/LNK拖入伙伴、快捷栏或模块窗口后确认添加，支持启动参数、工作目录和Windows管理员启动。
- 程序路径失效时寻找同名候选，经确认才更新；被动检查不弹确认，取消保留原路径。
- JSON动作模块与ZIP独立进程模块可独立安装、升级、停用或移除。

## 2. 启动器与桌面操作

- 顶部快捷按钮拖拽排序，顺序持久化；溢出项收进“更多”，可在排序窗口调整。
- 输入文件或目录路径，后台提供候选；方向键、Tab、回车、双击操作，支持中文、引号、空格与环境变量。
- 保留应用拼音/简称、收藏排序、上下文与最近使用、剪贴板历史及敏感内容保护。
- 保留多显示器吸附、悬停展开、直接拖出、全屏隐藏和自定义伙伴名字。

## 3. 皮肤与完整界面主题

- 五套球队皮肤覆盖各类动画，窗口、按钮、菜单和提示同步换色。
- 新建完全独立的主色、辅色、强调色与标语，预览明暗、圆角和透明度，不必依赖球队。
- 导入1024×1024PNG球衣；未选图时可生成纯色球衣，默认巴萨仍使用原始服装。
- `.leoskin`导入/导出球衣与主题，不包含应用路径、模型Key或个人记录；每次导入新增皮肤。

## 4. 媒体、拖放与便签

- QQ音乐仍定位为快速点一首歌，不维护或同步歌单。
- 统一媒体控制支持Windows媒体会话与PotPlayer，提供播放、暂停、切换、停止及媒体文件打开。
- 文件、图片、文字、网址进入统一拖放动作面板，按内容及模块开关显示操作。
- 新增临时便签：无需日期、快捷保存、编辑/删除、选日期并确认转为待办，保留全文及转换标记。
- 右键菜单按清单与记录、应用与媒体、组合动作、外观分组，原动态皮肤和组合菜单保留。

## 5. 版本命名与更新兼容

- 对外正式标签及界面显示版本为 **v1.00.0**。
- Windows/.NET内部版本比较按 **1.0.0** 进行；更新器按标签保留安装包文件名中的零位。
- 发布页额外提供同内容`v1.0.0`兼容附件，供旧版更新器使用；手动下载选择`Leo-v1.00.0-win-x64.zip`。
- 发布包仅从源码生成，附SHA-256及文件清单，不包含本地运行目录、个人配置、语音模型和备份。

## 使用与验证

- 下载ZIP后完整解压，运行`Install-Leo.cmd`；更新选择原目录。
- 使用说明、模块协议和皮肤格式已同步更新，截图为演示数据。
- 本次执行版本命名、下载/校验兼容和发布包验证；近期功能的86项定向检查已在v0.53.0完成，不重复测试未改动功能。

当前大版本不加入新一轮建议功能。便签目前不包含在配置迁移导出中，手动迁移需单独保存`leo-notes.json`；提醒仍依赖Leo保持运行。
