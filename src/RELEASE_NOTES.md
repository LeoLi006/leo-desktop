# 当前版本更新说明

## v0.45.0 · 稳定操作、自然清单与独立安装

### 软件启动与耗时反馈

- Clash 和 QQ 音乐采用统一操作队列，合并相同等待请求；同一客户端的不同动作顺序执行。
- 根据启动、等待、执行阶段显示反馈，等待较久后提供取消，失败提供重试。
- 代理核对系统状态和本机监听；点歌核对客户端接收；暂停和继续读取媒体状态。

### 桌面、足球与异常恢复

- 普通动作与吸附首帧渐变衔接，展开途中拖动平滑接管，角落按拖动方向选择吸附边。
- 足球成为可选模块：入口、窗口和后台查询同步停用，保留关注、缓存与已有提醒。
- 足球缓存标明更新时间，查询失败保留内容；音乐搜索和聊天有各自的重试入口。
- 工具调用后的失败重试先恢复草稿并提示核对，避免自动重复执行已完成动作。

### 清单与设置

- 本地解析相对日期、中文时刻、每天或每周重复；确认窗口可编辑，确认后才保存，无需模型 API。
- 运行检查提供启动项、软件路径和快捷键冲突的对应处理入口，检测无异常的项目不提供盲目修复。

### 干净的 Windows 发布包

- Windows x64 自带运行组件，解压后可通过安装入口安装或更新，无需开发环境。
- 首次启动选择可选模块；客户端、API 和本地语音可稍后配置。
- 更新前备份程序和配置，失败恢复原程序；安装入口支持手动回退，保留当前个人数据。
- 仅打包源码构建结果、公共素材和文档，排除个人 JSON、Key、模型、录音、日志及调试文件。

验证采用本次功能的模拟操作、窗口预览、动画和安装故障注入检查；不自动切换实际代理或播放音乐。发布包额外执行自带运行时启动及完整性检查。
