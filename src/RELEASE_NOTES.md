# Leo v1.02.1 · 提示框与通知按钮修复

本轮只处理用户报告的操作提示残缺、通知收纳盒按钮误触，以及误触后的位移和动画状态异常。未新增功能，未上传 GitHub。

## 修复内容

- 操作提示的文字采用相同规则测量和绘制；短提示、长提示和带重试按钮的提示切换时，完整更新尺寸、圆角区域和内容，避免旧画面残留与文字裁切。
- 有未读通知时，原先的小圆点改成更清晰的信封按钮；有效点击范围扩大至 36×36，覆盖图标周边。
- 通知按钮使用独立的按下和松开流程，不进入桌宠拖动或搜索切换；松开后才打开收纳盒，移出范围松开则取消。
- 鼠标捕获丢失时清理待处理点击和拖动状态，避免下次操作沿用旧位置或持续播放移动动作。
- 通知窗口获得焦点时保持桌宠展开，避免操作收纳盒期间自动吸附。

## 定向验证

76 项相关检查通过：28 项提示框及鼠标交互、4 项原有代理提示检查、44 项吸附直接影响检查。覆盖三种桌宠大小、实际 Windows 鼠标消息、捕获中断、范围外松开、普通搜索开关、重复长短提示及五套主题切换；检查未改变系统代理或调用模型 API。

本轮之后转入性能与鲁棒性工作；具体优化批次先由用户审批，再修改代码。相关开源选型依据见源码目录中的 RESEARCH.md。
