# v0.51.0 · 统一动作入口、扩展模块、主题编辑与媒体控制

## 修复

- 设置中的名字与大小说明标签遮住了输入框、滑块，导致鼠标操作失效；已缩短标签范围。
- 保存设置时先验证名字、尺寸和主题，不再因为未变化的开机启动项被重复写入而阻断保存。
- 自定义球衣贴图在内存中使用副本，移除时不再因图片文件占用而失败。

## 统一动作入口

聊天、语音、搜索框与自定义组合复用`ActionDispatcher`和模块接口；模型的应用查找、打开也走同一入口。并发相同操作合并，停用、错误、取消和递归检查统一处理。搜索保留拼音/简称，可直接输入明确指令或使用冒号入口；自然清单先在本地解析并确认。

## 模块扩展

设置 → 功能 → 管理扩展模块。支持声明式JSON与携带自有程序的ZIP模块，独立导入、启停、版本更新、移除。独立进程通过UTF-8 JSON协议执行，可新增逻辑而不改主程序。提供取消与超时；运行期间禁止更新、删除；模块数据独立保存。协议见 [MODULES.md](MODULES.md)。

## 主题与球衣

设置 → 常规 → 主题与自定义球衣。逐皮肤保存强调色、明暗、圆角和透明度，即时预览，保存后应用。自定义1024×1024 PNG球衣可导入、命名和移除；导出模板可用于制作自己的纹样。新皮肤出现在右键菜单中，覆盖原有全部动画。规格见 [SKIN_FORMAT.md](SKIN_FORMAT.md)。

## 媒体控制

右键 → 媒体控制，连接Windows媒体会话与PotPlayer窗口。选择目标后支持播放/暂停、上一项、下一项、停止，也可选择文件用PotPlayer打开。QQ音乐快速点歌保留，窗口内增加媒体入口。PotPlayer路径可手动指定；所有Leo媒体控制在本机执行，不调用模型API。

## 验证与数据

定向验证设置实际保存、各入口共同分派、模块安装/升级/移除、独立进程协议、取消/超时、球衣导入/移除和主题预览，并检查直接受影响的动画与主题。真实Windows媒体接口进行了只读检查；PotPlayer当前未运行，未对真实播放内容发送控制。

本地配置、API Key、语音模型、清单和聊天记录保留。

操作见 [USER_GUIDE.md](USER_GUIDE.md)，绘制说明见 [ANIMATION-NOTES.md](ANIMATION-NOTES.md)。
