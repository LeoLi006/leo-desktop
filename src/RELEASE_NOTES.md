# v0.52.0

- 搜索框顶部在QQ音乐旁加入可独立关闭的PotPlayer媒体控制按钮。
- 内置本机应用与自定义应用统一管理启停、程序路径、图标；新应用支持EXE/LNK、独立启动动作、搜索及移除。
- 自定义快捷按钮排在足球、QQ音乐及PotPlayer之后，溢出横向滚动，避免遮挡大小滑动条。
- 搜索框直接输入绝对路径打开文件或文件夹，支持中文、空格、引号和环境变量；不存在时保留窗口并提示。
- 新增清晰的新建皮肤窗口，可选基础主题、独立命名及导入PNG；也可复制现有球衣，新皮肤不覆盖旧皮肤。
- 默认巴萨的复制皮肤保留原动画服装；自定义图标在统一绘制入口渲染。

使用入口和限制见使用说明第24节。应用路径、图标、皮肤和个人配置仅保存在本机，不进入源码提交。
