# Leo v1.00.2 · S03 模块状态与吸附修复

本轮按用户批准完成S03，并处理附加的左右吸附与自动更新提醒。仅本地提交和安装，不上传GitHub。

## 新增

- 设置的功能页、运行检查页增加统一“模块状态与处理”入口。
- 内置可选模块、自定义应用与扩展区分未安装、未配置、失效、已停用、等待就绪、正常和失败；提供配置、启用、路径修复、扩展管理或重新检测入口。
- 共享动作入口与客户端启动流程记录执行状态；失败保留原因，过期动作结果不会覆盖新请求。
- 常规设置新增自动更新提醒开关：启动延后检查，之后每24小时检查；仅发现较新正式版提醒，同一版本不重复，断网静默。检查不会下载或安装。

## 修复

- 左右吸附进入动画前贴齐工作区边缘，消除允许判定偏差与绘图内边距叠加造成的缝隙。
- 吸附绘图与点击区域统一使用窗口尺寸，避免大小换算造成边缘错位。

## 验证与说明

64项本轮定向检查覆盖模块状态优先级、真实动作生命周期、版本比较、提醒开关与日程、断网处理、设置保存及左右吸附几何；另44项吸附动画与交互检查通过。未执行无关功能的全量检查。

运行检查不启动外部软件；“正常”不等于外部程序已启动。失败后的重新检测不自动重放动作。使用说明第27节说明状态与更新提醒。
