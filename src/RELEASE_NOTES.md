# v0.49.1 · 自选皮肤与动画修正

## 本次变化

- “比赛日装扮”改为独立的**皮肤**功能：默认巴萨，可选阿根廷、西班牙、迈阿密国际、曼城。
- 删除自动跟随比赛和关闭装扮入口；切换不依赖足球模块、赛程或联网，专注期间保持选择。
- 选择跨重启保留；旧手动装扮迁移为对应皮肤，旧自动/关闭状态迁移为默认巴萨。
- 修正右侧吸附部分帧眼睛方向不一致：角色动作与左侧对称对应，统一朝向屏幕内侧；胸前文字保持正向。
- 保留上一版的平滑半透明轮廓、清晰球衣取样和默认头部比例。
- 清理废弃的独立球队图集、旧单张待机素材及过期动画说明；当前文档只描述现行用法。

## 相对上一个公开源码版本的其他新增

- 通知收纳盒、25/45/60分钟临时专注、重要事项提示。
- 剪贴板暂停、来源应用排除、常见敏感内容保护和自动过期。
- 55支国家队，总目录152支，国家队赛事详情与积分榜切换。
- 软件操作统一启动、等待就绪、执行与反馈；清单自然输入和安全修复入口。
- 手动检查更新与不含个人数据的 Windows x64 安装包。

## 安装与更新

1. 从当前 GitHub Release 下载 `Leo-v0.49.1-win-x64.zip`；同页提供SHA-256校验文件。
2. 完整解压，运行 `Install-Leo.cmd`，选择 Leo 专用安装目录。首次启动选择需要的模块。
3. 更新时选原目录，按安装器提示备份和更新；失败可回退，个人配置与清单不会被发布包覆盖。

安装包包含 Windows 桌面运行时，无需开发环境；不包含API Key、个人配置、清单、缓存、日志或语音模型。QQ音乐、Clash等外部软件仍需自行安装。

完整操作见 [USER_GUIDE.md](USER_GUIDE.md)，皮肤与绘制说明见 [ANIMATION-NOTES.md](ANIMATION-NOTES.md)。历史版本保留在 GitHub 标签与发布记录，本地程序和构建副本仅保留当前版。
