# Leo v1.00.1 · S01 入口显示与模块启停分离

本轮仅实现用户单独批准的路线图S01；未开始使用方案或能力中心，不上传GitHub。

## 本轮变化

- 设置 → 功能新增“入口显示”，为六个内置可选模块与自定义应用选择快捷栏显示、仅菜单显示或仅搜索调用。
- 显示方式与模块开关独立保存，隐藏后仍可通过搜索、聊天、语音、组合或已有快捷键调用已启用能力。
- 脚下工具与顶部快捷栏同步隐藏、恢复；没有工具时收起空下拉区，保留原快捷排序。
- 右键“应用与媒体”补齐足球、终端、Clash、Edge和自定义应用入口，并与显示方式及启停状态同步。
- 停用音乐时释放其Leo点歌窗口活动；不退出外部播放器，不擅自关闭代理。
- 入口编辑先确认，再随设置统一保存；取消不应用。旧配置与旧迁移文件保留原有显示方式。
