# 当前版本更新说明

## v0.44.3 · 静默切换与仓库整理

### Clash 静默操作

- 系统代理开关直接在现有后台界面执行，不再恢复、激活或最小化客户端主界面。
- Clash 尚未运行时，Leo 启动前会启用客户端原生静默启动设置，仅调整 `enable_silent_start`，不改订阅与节点。
- 保留真实系统代理状态校验，失败时仍给出完整提示与重试入口。

### 定向验证

只验证本次修改：静默配置的最小变更、幂等处理、从非首页后台切换代理、窗口是否意外显示，以及切换后恢复原代理状态。

### 文件整理

主分支删除过时的测试输出、旧版本说明、已废弃的吸附素材与动画预览。当前源码、有效测试、当前动画、许可证、依赖校验和必要的素材来源保留。历史版本仍可通过 Git 标签查看。

本机旧日志和临时检查产物清理；个人配置、模型、清单、聊天、剪贴板与备份保留，不提交 GitHub。

### 公开项目与反馈

仓库公开供查看和下载，使用说明见首页与 [USER_GUIDE.md](USER_GUIDE.md)。问题通过 GitHub Issues 反馈。普通访问者没有主仓库写权限；Fork 及外部提交不会直接改动本仓库。
