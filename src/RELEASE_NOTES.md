# v0.50.0 · 多屏停靠、完整球队主题与自定义名字

## 使用者可见的变化

### 1. 多屏吸附

- 支持横排、竖排、错位和负坐标显示器。
- 共享接缝不吸附，跨屏拖动连续；只在外侧边缘收起。
- 错位屏幕仅对没有邻屏遮挡的边缘段吸附，避免头部跨屏裁切。
- 跨屏处存在侧边任务栏也可拖过；释放时以可见工作区安置。
- 移除显示器或改变布局后自动展开并恢复到可见区域。

### 2. 五套完整界面主题

右键 → 皮肤：巴萨、阿根廷、西班牙、迈阿密国际、曼城。

皮肤同步控制角色球衣、窗口背景、标题、按钮、右键菜单、滚动条、日历、聊天气泡、提示框与设置滑块。已经打开的窗口即时换色，聊天草稿保留。日历侧栏的队徽和口号也随队伍变化。错误与成功提示保留语义色；Windows 文件选择等系统对话框及第三方软件遵循各自主题。

聊天窗口使用相同主题的标题按钮，同时支持边缘缩放、最大化、还原、最小化和拖动。窗口位置记忆继续支持聊天尺寸恢复。

### 3. 自定义名字

设置 → 常规 → 伙伴名字，填写 1～24 字符后保存。标题、应用搜索、聊天称呼、主要菜单和托盘同步更新。默认 Leo；旧配置自动使用默认值，迁移和导出保留新名字。改名不移动文件或删除原有数据。

## 安装与隐私

下载当前 Release 的 `Leo-v0.50.0-win-x64.zip`，同页提供 SHA-256。完整解压后运行 `Install-Leo.cmd`；更新选原安装目录，按安装器提示保留配置并备份。

发布包从源码构建，含所需 Windows x64 桌面运行时；不含个人配置、密钥、清单、聊天、缓存、日志、备份或语音模型。发布截图使用空白示例数据。

## 验证范围

本次仅检查主题、名字、多屏停靠、与其直接相关的动画和聊天缩放，以及发布包。多屏排列通过模拟几何布局检查，并非声明已在所有多显示器硬件或混合 DPI 组合上实测。
