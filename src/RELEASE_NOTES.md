# Leo v1.02.0 · 速记、统一操作与故障隔离

本轮经用户批准完成S04、S05、S09、S11，并处理附加的左右吸附结束跳动与单功能故障隔离。仅本地提交和安装，不上传GitHub。完成后暂停新增功能，先调研可复用的开源实现。

## 新增与调整

- Ctrl+Alt+N一句话速记，Enter保存、Esc取消；可在设置改键，方案可保存；兼容旧配置中的按键占用。
- 便签搜索、置顶及便签/已转待办/全部分类；原文和关联记录保留，写入失败保留输入。
- 普通窗口统一就近显示、非长期置顶、焦点处理和最小化恢复；补齐常用选择面板的Enter、方向键、Tab和Esc规则。
- 轮询异常暂停对应活动；吸附渲染异常恢复普通待机和按钮；应用索引回调检查生命周期；连续异常的普通窗口可以隔离后重开。
- 运行检查展示本次隔离状态，只记录功能名、异常类型和次数，避免保存输入或异常原文。

## 吸附修复

左右动画改用脸部中心轨迹和相邻姿态的预乘像素插值，消除最后姿态切换造成的视觉跳动；点击区域与显示采样同步。

228项相关检查通过：39项本轮交互与故障注入、44项吸附动画、36项方案、64项更新与状态、45项入口显示。覆盖写入失败、视图异常、轮询停止、窗口隔离、损坏吸附素材降级和终态像素连续性。未运行无关全量测试。
