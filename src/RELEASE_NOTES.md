# v0.53.0

## 快捷入口与应用模块

- 顶部快捷按钮支持拖拽排序、顺序持久化；放不下时收进“更多”，可在排序窗口调整所有入口。
- EXE/LNK可拖到伙伴、顶部快捷栏或应用模块管理窗口，读取名称和默认图标，确认添加。
- 自定义应用支持启动参数、工作目录、Windows管理员启动；搜索和快捷启动沿用这些配置。
- 路径失效时查找同名候选，经确认后修复；被动运行检查不弹修复窗口，取消不改变设置。
- 搜索框后台补全文件和目录，支持方向键、Tab、回车、双击，取消过期查询并防止关闭时重复释放。

## 皮肤与菜单

- 新建皮肤支持完全独立的主色、辅色、强调色、标语及自带球衣；不选图片可生成纯色球衣。
- 皮肤包导入/导出包含球衣与完整主题参数，不含个人数据；导入生成新ID，拒绝越界文件和重复条目。
- 右键菜单整理为清单与记录、应用与媒体、组合动作、外观、设置和退出，原动态菜单保留。

## 拖放与临时便签

- 统一拖放动作面板，识别文件、图片、文字、网址，按内容与模块开关提供少量动作。
- 文件选择入口也使用同一动作面板；新增PotPlayer播放、添加模块、记便签和确认添加待办。
- 临时便签无需日期，支持快捷保存、编辑、删除、指定日期转待办并防止重复转换。
- 便签与待办保持本地保存；明确口令及上述本地动作不调用模型API。
