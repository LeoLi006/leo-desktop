# 当前版本更新说明

## v0.44.4 · Clash 未运行时的一次点击开启

- 点击开启系统代理时，Clash 未运行则先静默启动，再等待就绪并开启代理。
- 启动进程出现不再等同于客户端就绪；持续重试后台控制，成功前核对系统代理状态与本机代理端口。
- 静默启动未创建首页时，使用 Clash 原生系统代理快捷控制，不要求打开主界面。
- 保留已有系统代理快捷键；缺失时选择空闲组合。启动前启用 Clash 原生静默启动和全局快捷控制，保留订阅及其他快捷动作。
- 已验证真实的“关闭客户端 → 静默冷启动 → 自动开启代理”，以及延迟就绪、端口尚未就绪、禁止重复切换和失败超时等本次相关场景。

冷启动检查入口 `--proxy-cold-test` 会受控重启 Clash 并开启系统代理，属于有实际网络状态变更的手动检查，不应作为日常全量测试自动运行。普通启动状态模拟检查入口为 `--proxy-startup-test`，不会操作真实客户端。
