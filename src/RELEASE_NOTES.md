# 当前版本更新说明

## v0.46.0 · 通知收纳、专注保护与国家队

### 通知与专注

- 增加通知收纳盒，保留最近200条提醒、操作结果和失败记录；同一操作的重复反馈合并。
- 右键或未读小金点打开，支持已读管理、回到清单，以及当前会话内的重试；重试遵守模块开关。
- 增加25／45／60分钟临时专注，普通提醒收进通知盒，重要事项和比赛提醒可保留弹窗。
- 清单右键可标为重要，专注状态保存在本机，到期完成一次，重启不重新计时。

### 剪贴板保护

- 支持暂停10／60分钟、排除指定应用、常见密钥与私钥识别。
- 尊重Windows敏感内容标记，结合来源进程和前台进程；恢复后不补录。
- 非收藏记录可选1／7／30天或不自动过期，默认7天；收藏保留。

### 足球与比赛日

- 新增55支国家队，总目录152支，管理关注增加国家队筛选；普通国别话题不会自动转成足球分析。
- 国家队详情支持赛程及赛事积分榜选择，沿用同窗口返回、比赛清单和提醒。
- 新生成曼城、迈阿密国际、阿根廷、西班牙四套透明待机服装；支持按当天关注比赛自动展示和手动预览。
- 其他球队采用队徽提示，足球模块停用或专注期间收起比赛日状态。

### 手动更新

- 设置里增加手动检查更新，区分源码标签与可安装的正式发布。
- 下载验证SHA-256、文件清单、版本及路径后打开安装确认，支持取消，沿用更新备份和回退。
- 不自动联网检查，不自动安装，不上传GitHub或读取本机GitHub凭据。

验证限定为本次新增功能、通知流程、绘制和安装包直接影响范围；不自动切换代理、播放音乐或调用用户的模型API。
