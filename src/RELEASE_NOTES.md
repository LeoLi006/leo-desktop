# Leo v1.01.0 · 使用方案与快捷操作

本轮整批范围经用户批准：A1使用方案、方案后台活动管理、S02按钮右键管理、S07拖放复用应用配置，以及吸附头部比例修复。仅本地提交和安装，不上传GitHub。

## 新增

- 设置 → 常规 → 使用方案：四种起始模板，自定义保存、更新、重命名、删除、重置、切换差异预览及导入导出。
- 方案字段白名单：不携带本地程序路径、图标路径、启动参数、API配置及个人记录；导入不执行程序，切换需确认。
- 桌宠陪伴方案停止应用索引、上下文观察、剪贴板记录、足球同步及可选模块轮询；保留核心能力和已有数据。
- 可选模块停用时取消排队或等待中的客户端动作，阻止旧窗口继续发起请求；重新启用后可以使用新请求。
- 可选快捷按钮右键管理；自定义应用支持名称、图标、参数、工作目录和管理员选项，内置按钮仅提供适用配置。
- 拖放“选择应用打开”优先复用已配置模块，再提供临时浏览程序；正确追加并引用每个文件路径。

## 修复

- 吸附动画按待机脸部比例校准，统一过渡帧宽高比，半隐藏状态平滑缩小，避免只剩头部显大。
- 设置写入失败向上报告；方案切换失败恢复原配置，不假报成功。
- 取消应用索引后拒绝过期扫描结果，关闭不需要的观察器与轮询。
