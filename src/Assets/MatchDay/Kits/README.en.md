# Jersey texture assets

[简体中文](README.md) | **English**

These are AI-generated cartoon jersey textures, not official photographs or an endorsement/license. They project onto clothing without redrawing the character. No image generation/network request occurs at runtime.

Each is an opaque1024×1024 flat texture with chest details concentrated above. Tiny sponsor lettering simplifies at companion size. Barcelona uses original animation clothing, without a separate match-day Barcelona skin.
