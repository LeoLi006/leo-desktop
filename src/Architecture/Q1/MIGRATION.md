# Q1：兼容规则与逐批回退

这是迁移约束，不改变当前运行格式。当前动作完整清册由 `q1_audit.py` 从 LeoActions.Names 生成；本批不删改旧 ID。

## 保留与转换

| 对象 | 保留规则 | 新旧边界与验收 |
| --- | --- | --- |
| ActionRequest / Task<string> | 保留 action/value/source 和旧工具调用形状；value 仍为字符串 | 旧入口适配器按动作显式解析成类型化参数；未知字段不静默丢弃。旧文本包装为 legacyMessage，不靠中文关键词猜成功。 |
| 内置动作 ID | LeoActions.Names 原值不重命名；ModuleCatalog 当前归属留快照 | 新模块内部归属变化不等于外部 ID 变化；同一 ID 只能有一个执行器。未知动作明确失败，不随机匹配。 |
| local:<GUID> / local_app_open | GUID、应用启动参数、工作目录、管理员选项及图标保留 | 参数直接传启动 API，不通过额外 shell；数据导出继续区分本机配置与公开样例。 |
| ext:<id>:<command>、LeoModule/1 | 旧 manifest、actions 与 stdio 都继续可读 | v1 worker 只理解原来的一行 JSON，不擅自给它发新信封。版本能力协商后才采用新协议；不支持时明确拒绝。 |
| 老字符串结果 | 仍向老聊天/UI 返回原文本；异常保持失败 | 结构化结果为新接口；旧执行器无证据时标 unknown/legacy，不编造 confirmed。取消不等于回滚已完成的启动/播放/代理动作。 |
| ComboStep / CustomCombo | 保留 Kind/Value/Label、顺序、现有 ID 与旧场景兼容 | 新工作流另有版本，按步骤显式迁移。旧组合可原样执行，不覆盖用户文件；不把旧“忙”文本自动判断为成功。 |
| Preferences / 入口 / 方案 | 隐藏不等于停用；当前 core 权限不改；缺省字段沿用旧逻辑 | EntryDisplayModes 的 shortcut/menu/search 与 leo-profile-1 继续使用。方案白名单不加入路径、密钥或个人记录；未知可兼容键保留规则逐种格式明确，不全局套用。 |
| 清单 / 便签 | 保留 ID、重复例外、完成/提醒、比赛关联、便签转待办关联 | 不通过导出再导入来“迁移”存储，避免换 ID；原子保存不是跨文件事务。 |
| 配置迁移 / 回滚 | 迁移前同目录备份并验证可读；失败保留原配置 | 模块程序版本回退与数据版本回退分开；旧版无法读新数据时必须恢复对应备份，不直接覆盖。 |
| 窗口 / 快捷键 / 主题 | 继续 WindowPositions、WindowInteraction、ApplySettings、UiTheme | 不重新做另一套位置/热键注册；新增生命周期钩子必须重复调用安全，并清理静态事件。 |

## 迁移批次与开关

1. **Q2：最小闭环**。先审定最小契约，再选自定义本机应用启动作试点；内置启动器作为下一步，不同时触碰代理和音乐。用假启动器验证注册、启停、参数、窗口无焦点变化、结果和兼容入口，真实启动仅在用户需要时单独验证。
2. **后续批次**。先读动作和窗口打开，再有写入动作，再后台生命周期；逐项采用旧实现适配器。共用同一个调度器，禁止新旧执行器同时消费同一请求。迁移状态只用于选择实现，不把个人路径写进描述文件。
3. **业务组合和大脑**。基础动作拥有类型化结果、取消和结果证据后，再做工作流数据引用；模型只能使用注册表中已启用能力。明确口令继续本地执行。涉及副作用、部分完成或歧义时先解释/选择，不隐式重试。

## 每批开工前固定的核对清单

- [ ] 明确哪些动作迁移、哪些旁路仍保留、旧数据是否完全不变。
- [ ] 保存源码提交与测量基线，指定真实执行与假执行范围；先定性能比较规则再测。
- [ ] 模块停用时拒绝新请求、取消归属任务，隐藏入口仍可调用；窗口关闭不误取消模块共享任务。
- [ ] 同动作从聊天、搜索、语音、按钮、组合得到一致的结构化结果和单次副作用；模型不可绕过确认。
- [ ] 取消、超时、过期回调、重复请求、故障及恢复有定向检查；只检查本批直接影响。
- [ ] 同机重复测量无持续资源增长，变化落在事先规定的比较规则内；无法归因的差异标记待调查。
- [ ] 回退时关闭新分派、恢复旧实现和所需数据备份；真实外部副作用单独提示，不伪装撤销。

## Q1 交付政策

Q1 不注册新业务模块、不换旧协议、不更改用户配置。只更新源码中的内部规划/工具/报告，提交本地 Git；不改发布号、不做安装包、截图、README 宣传材料或 GitHub 发布。下一批继续先审批。
