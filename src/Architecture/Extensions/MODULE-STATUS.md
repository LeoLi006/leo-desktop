# D04：原模块状态窗口的契约投影

日期：2026-10-21；基线0a67502。只完善已有状态窗口，不新增模块、配置中心、执行权限或轮询。

## 读取与归属

原ModuleStatuses.Read保留内置功能的软件路径检查和API配置摘要。自定义本机应用及已安装LeoModule/1扩展按模块身份各显示一行，不再把扩展贡献的每条搜索/菜单入口误认成一个待安装应用。

EntryContributions.ReadStatusContract通过已有偏好绑定读取当前注册表，只返回ModuleContractSnapshot，不提供执行器、不改配置、不准备路径、不执行动作。自定义应用还核对调用方配置与当前注册配置一致；未保存的不同草稿不能借用旧配置的检查结果。扩展仍从原安装目录读取，使用上一批兼容检查和原执行目标依赖检查。

每行补充来源：自定义应用（绑定数据包时附其版本）、声明式扩展或独立进程扩展；扩展附安装版本与显式启停状态。名称、版本及存在性每次沿原窗口刷新重新读取，不缓存过期的模块对象。来源与说明可悬停查看完整内容，刷新前清理旧提示绑定，窗口释放时销毁提示组件。

## 状态语义

| 情况 | 展示 |
| --- | --- |
| 配置显式停用 | 已停用；不以坏路径覆盖停用状态，不因隐藏入口推断停用 |
| 宿主范围或声明依赖不可用 | 失效，并显示兼容原因；不下载或启动依赖 |
| 当前契约/配置或被动依赖检查失败 | 失效或未检测；不采用异常消息中的路径/参数正文 |
| 未绑定契约、不同草稿、过期配置 | 未检测，不借用旧结果报成功 |
| 依赖unknown/degraded | 未检测，说明未确认或部分可用 |
| 契约及被动依赖ready | 检查通过，明确不代表程序已启动或运行正常 |
| 归属不一致 | 失效，不采用其他模块的快照 |

旧内置功能的等待、失败及原处理规则保留；本批扩展/应用摘要展示当前配置、兼容与被动依赖，不作为进程探测或业务健康证明。原API摘要仍只检查配置是否填写，不主动连通测试。缺失契约不通过临时执行扩展探测。

## 窗口与处理入口

继续使用ModuleStatusForm原1500ms窗口刷新，没有新增计时器、后台扫描或常驻订阅。应用行通过原设置中的应用模块编辑器处理，扩展行进入原扩展管理，内置模块及API保持原路由。状态读取方法也被原运行检查复用；其状态标签由“正常”改为“检查通过”，避免将被动检测当成运行成功。

停用/重新启用、改名/更新及移除后，下一次原刷新读取当前状态；移除项不保留幽灵行。一个应用服务异常或坏扩展声明只影响对应行，其他模块继续展示。未知普通贡献模块的完整状态中心仍未在本批实施；不把此次投影称为全部D04完成。
