# C01/C06/D01：旧扩展接入统一契约与入口

日期：2026-10-21；基线cc70e91。本批复用旧LeoModule/1安装与执行实现，补内部适配，不发布新包格式或插件市场。

## 已交付

ExtensionLeoModule现实现既有结构化动作、参数适配、模块契约和入口贡献接口。注册表读取扩展贡献时复用现有ExtensionStore.Load，不执行worker或启动依赖；普通内置模块注册路径保持。模块描述包含动作、执行类型、依赖、输入、结果、超时及取消说明，旧扩展版本按原Version解析规则规范化为内部数值表示。

内部契约允许stdio运行类型，用来准确描述原独立进程协议；这不是引入新的执行器或同进程代码加载。旧包Format、字段、命令编号ext:<module>:<command>、口令和标准输入/输出协议保持。

## 输入与结果兼容

| 入口 | 规则 |
| --- | --- |
| 旧字符串动作/口令 | 声明式目标仍使用包内固定Value，忽略旧调用中多余覆盖值；worker沿用非空请求值覆盖包内值；保留旧分发器16000字符上限 |
| 新结构化动作 | leo-action/1，parameters只能为空对象或唯一value字符串，拒绝未知/重复字段、错误类型和协议；声明式非空覆盖明确拒绝，worker允许覆盖 |
| 声明式结果 | 经原分发器转交真实目标，保留结构化Data和Evidence，不把字符串猜测成成功事实；目标失败/取消仍进入失败/取消路径 |
| worker结果 | 仍要求ok/message、合法行长、正常退出；内部completed表示协议响应完成，不证明任意外部效果或状态已经达成 |

声明式适配的外层预算为120秒，原目标仍执行自己的超时；worker外层使用包中TimeoutSeconds（1～120秒），同时保留ModuleWorker原有超时与清理。没有自动重试、补偿或提交后撤销承诺。成功结果标为私有，原安静执行摘要不保留Data及完整返回正文；本批未全面改造原错误日志策略。

## 入口与生命周期

每个扩展命令提供ext:<module>/<command>入口身份，目标为leo-module-entry:身份。默认仅搜索，保留原“输入口令调用”的习惯；可在原入口显示设置中选择菜单或快捷栏，原排序/隐藏规则适用。简称来自原Phrases，不新增图标下载或常驻轮询。

搜索结果、模块菜单和快捷按钮复用已交付渲染器，点击重新核验当前注册/启用状态，不退回程序路径启动。不实现IBrainContributor，因此不会自动成为模型工具。

扩展管理完成导入、更新、启停或移除后，通知已绑定宿主取消失效请求并刷新入口。只读设置草稿仍不绑定执行器或刷新回调。已运行请求持有旧描述时，通过ConfigurationIsCurrent核对当前已安装描述，更新会使旧请求取消；扩展运行中禁止移除/更新包、标准流限制、超时/取消及辅助进程回收沿原实现。

扩展描述仍从现有磁盘目录按需读取，没有新增监控线程或扫描计时器；本批未建立任意规模扩展目录的性能保证。独立进程以当前用户权限运行，既有导入确认不等于权限沙箱、签名认证或来源可信证明。
