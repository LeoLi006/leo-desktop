# C05/R01：自定义应用入口试点

## 格式与范围

`leo-entry/1` 是宿主内部纯数据格式，由 `EntryContributions.Read` 从当前配置生成，不增加持久化格式或缓存。仅覆盖自定义本机应用。

`ApplicationEntry` 包含裸应用编号、模块/动作编号、名称、图标引用、启用状态、显示方式、搜索目标与简称、固定编辑器标识。快捷栏、菜单、搜索目录、入口设置和应用模块列表从它投影。不携带委托、控件、启动参数或可执行载荷。

## 归属及兼容

- 编号必须为原有 GUID；模块与动作同为 `local:<GUID>`。重复编号、跨归属动作或未知编辑器拒绝读取。
- 显示配置继续使用裸编号，缺省快捷栏；快捷栏顺序、菜单原始顺序、目标去重、收藏与原简称评分保留。
- 隐藏不改变启用状态。按钮与已打开菜单点击时重新确认存在且启用；最终执行仍经原注册表。
- 搜索匹配相同路径优先启用的自定义配置；仅有停用配置时仍保留关联，由执行器阻止绕过停用。
- 路径失效不阻止描述读取，保留路径修复。参数、工作目录与管理员选项只由原执行器处理。
- 编辑器从草稿生成同一格式，不启动客户端、读取 Key 或联网。运行描述含本机引用，不导出到公开清册。

## 验证边界

锁定构建零警告。入口专项57项、Q2原四入口启动60项通过，涵盖归属、重复编号、固定编辑器、更名、图标简称、隐藏、停用与移除，以及原显示排序启动行为。只做相关验证；内置入口、代码插件和新业务不在本批范围。
