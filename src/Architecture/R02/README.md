# R02 第一批：后台活动归属与停用收尾

日期：2026-10-20。仅覆盖批准的足球刷新、音乐窗口请求、媒体窗口轮询和请求。沿用现有开关、数据格式、外部客户端和动作编号；不增加后台监控线程或新的常驻计时器。

## 最小生命周期接口

`ActivityOwner` 是一个所有者的取消代次；`Begin(kind, callerToken)` 返回 `ActivityLease`。租约记录活动类型并链接调用者取消。`Reset` 先作废旧代次，再在锁外通知取消，新请求使用新代次；`Dispose` 永久停止接受请求。坏的可恢复取消回调不阻断其他取消及令牌源释放，只向 Trace 写异常类型。

`ActivityLease.Current / ThrowIfNotCurrent` 用于发布结果前的检查；请求实际结束后由 `using` 释放租约、令牌和登记条目。取消不等于完成；仍未返回的活动继续计数，带“取消收尾”数量。一个调用者取消不会取消其他所有者或新一代请求。注册表不保留完成历史、不保存业务正文，不将计数写入个人数据。

本机制负责取消与在途登记，**不是**资源容器或强制终止器。窗口仍明确停止/释放自己的 WinForms Timer；不能杀死无视取消的第三方任务，也不能撤销已提交的外部播放命令。后续模块接入不能只登记计数而省略真实资源释放。

## 本批资源归属

| 所有者 | 登记类型 | 隐藏或窗口关闭 | 模块停用 / 宿主退出 |
| --- | --- | --- | --- |
| FootballQueries | schedule-refresh、team-refresh、event-refresh | 窗口取消自己的订阅；其他订阅者和宿主共享缓存保持可用 | Suspend 切代并取消；Dispose 停止新活动。沿用查询缓存、配置代次及发布前校验 |
| MusicForm 搜索 | search | 搜索取消；隐藏不复活窗口；共享候选事件进入UI队列时携带呈现代次 | 窗口释放时取消、解绑事件；启用后创建新窗口 |
| MusicForm 控制 | control | 保留已提交点歌/播放控制的现有语义；不因隐藏而误称撤回成功 | 释放窗口取消其等待和后续处理；晚到成功/错误不写回关闭的界面 |
| MediaForm | polling、refresh、control | 隐藏停止轮询，取消窗口请求并切代；重新显示立即刷新；旧任务不能清除新一轮刷新状态或覆盖错误栏 | 关闭停止并释放定时器、取消所有窗口活动；启用后新建窗口 |

音乐窗口的 search/control 统计的是**窗口订阅请求**；统一分发器可能先完成订阅取消，而共享提供者继续收尾。此提供者仍由既有分发器和原生队列管理，不能将窗口计数归零解释为 QQ 音乐、所有共享任务或整个宿主均已空闲。足球查询租约包围实际服务请求，包括等待资源队列和提供者返回。

入口显示模式沿用 S01：仅菜单或仅搜索不会停用能力；只有模块停用才关闭对应窗口及取消活动。关闭足球窗口不释放宿主共享查询服务。外部客户端不会被终止，已开启的代理或播放状态不被强行改变。

## 运行检查

现有“设置 → 运行检查”附加三类活动摘要，按中文名称显示类型、活动数和取消收尾数；没有活动时显示0。按打开检查页或“重新检查”取快照，不新增轮询。只覆盖本批登记的所有者，**不是**所有宿主后台工作的总数；不包含聊天正文、歌曲标题、媒体标题、球队查询、文件路径、API Key或完整参数，不调用模型。

原 `ModuleActivity` 仍是模块最近状态，不等于活动数量；本批没有强行合并两个语义。通用生命周期容器、其余宿主服务及代码模块热卸载尚未完成。
