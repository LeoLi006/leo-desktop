# M05 第二批：音乐与剪贴板能力迁移

日期：2026-10-20。按批准范围迁移现有 QQ 音乐点歌和剪贴板能力；不扩张业务功能，不更换发布版本。

## 音乐：窗口与能力分离

`MusicSession` 持有已查询候选、最近点歌和本次点歌队列。`MusicCapability` 负责校验、联网歌曲查询、排队、客户端调用和结果；`MusicClient` 是窗口使用的适配器。正常宿主与独立预览都注册同一种能力，不在窗口中再实现一套原生播放。

| 动作 | 行为 |
| --- | --- |
| music_open | 打开现有点歌窗口，可带查询词；显示候选，不擅自选歌 |
| music_search | 从已有 QQ 搜索提供者查询，返回最多8首有效候选；无需打开窗口 |
| music_play | 仅接受当前候选或最近点歌中可解析的精确歌曲编号 |
| music_step | 沿用本次点歌队列，方向仅为1或-1 |
| music_pause / music_lyrics | 原有播放暂停及歌词开关，复用客户端队列 |
| music_client / music_status | 打开并等待客户端、内部就绪查询；组合恢复经注册表核验 |

点歌窗口、页头快捷按钮、右键菜单、歌词快捷键、明确本地指令、聊天/语音和组合均进入统一分发器。旧动作与旧数据格式继续兼容。新增的歌词及状态动作是现有操作的接线，不新增面向用户的功能。

相同在途点歌合并，不同原生操作串行；歌曲搜索按请求处理，较早完成的过期搜索不会替换较新候选。停用模块、关闭相应请求、期限到达或路径配置改变时取消等待，旧计划和旧能力实例不能继续使用新配置。窗口关闭仍按原习惯隐藏，已有最近点歌与本次队列可继续使用；停用会释放窗口并清空候选/队列，不删除历史。

原生控制期限45秒，状态读取5秒。冷启动沿用 QQ 原生静默启动及就绪检查。显式打开客户端后只等待就绪，不再从等待方法重复启动客户端。启动、歌词和媒体控制检查取消；媒体辅助进程纳入宿主的帮助进程管理。

发送歌曲仅报告客户端提交，不把登录、版权限制或客户端拒播描述成“已播放”。播放暂停使用底层返回的 confirmed 标记区分观察与接受证据；歌词使用保守接受证据。已发送点歌后最近记录保存失败，返回提交成功并说明记录未保存，不能因历史写失败而重发歌曲。已有手动诊断命令的底层兼容函数保留，正常界面和组合不再调用旧 Hub 音乐包装。

最近点歌继续使用 `leo-music.json` 的列表格式，最多10项；新增原子保存及可恢复前版，只有保存成功才更新内存历史。无法读取且没有有效备份时保留损坏文件，不以空历史覆盖。

## 大脑的音乐边界

查询候选走现有 QQ 公共联网提供者，不调用中转站模型 Key；明确本地口令也不需要模型。只有复杂理解仍沿用现有模型路径。

模型工具由注册表生成。客户端缺失时仍可查询歌曲和打开点歌界面，原生点播/控制能力不提供给模型；模块停用则全部收回。模型必须先在本轮查询到歌曲编号，同名或多首含糊候选先澄清；明确歌名与歌手或精确编号才能确定目标。点播预览包含歌名和歌手，确认后才使用 Q4 执行器。原有最多4步、期限、配置检查、取消及未知效果重试规则保留。歌曲搜索结果和点歌正文不留在诊断历史。

## 剪贴板：本地数据操作统一

`ClipboardCapability` 注册原有窗口和文字收藏动作，并承接窗口内部的查询、复制、收藏切换、删除、清空、撤销和记录开关。`ClipboardClient` 供窗口和启动器使用，独立窗口也复用同一实现。

窗口查询只在执行结果中返回匹配记录的键；窗口从本机服务读取相应正文，避免每次刷新把图片或大段文字序列化经过分发器。私有结果在诊断历史中去除。自动采集与过期处理属于服务内部活动，继续使用原生读取、隐私检查及统一数据存储，不把数MB的图片编码放入动作请求。

只向模型公开“打开剪贴板窗口”。查询、复制、收藏正文等动作不提供给模型，并在执行层拒绝 `brain-*` 来源访问；模型打开窗口的回执没有记录正文或编号。明确的本地文字收藏同样检查敏感内容保护。

“记录历史”控制自动采集，和移除整个功能不同：关闭记录仍能手动查看、复制和管理已有收藏。停记、暂停、应用排除、Windows 敏感标记、敏感文字检测、过期设置及收藏豁免均保留；重新启用沿用序列号规则，不补抓停用期间的内容。记录开关保存成功后才更新内存与计时器。

剪贴板仍使用 `leo-clipboard.json` 的原列表格式，历史50条、收藏50条及原体积限制不变。变更先形成新快照，原子写入成功才替换当前内存记录及撤销帧。保存失败保留旧文件、记录和撤销状态；文本收藏一次提交，不再先添加后收藏，容量不足不留下半成品。撤销保留操作之后新采集的内容。损坏且无备份的文件不会被新采集覆盖。

窗口正常关闭和直接 Dispose 都释放刷新计时器与图片；宿主保存窗口引用，重复打开复用，退出时一并释放。复制的系统提交和辅助历史保存区分处理，避免历史保存失败被误报为复制完全没有生效。旧损坏文件列表显示读取提示，不让选择事件中断窗口。
