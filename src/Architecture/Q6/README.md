# Q6：数据型应用模块独立交付试点

交付日期：2026-10-20。仅对应已批准的自定义应用模块包，不迁移音乐、代理、媒体、足球或其它业务，不改发布版本。

## 用户入口

设置 → 功能模块 → 应用模块与图标。在原应用管理窗口中新增“导入 / 更新模块包”“导出所选模块包”，所选项下显示来源类型、版本、协议及本机依赖状态。

1. **导出**：选择自定义应用，检查公开名称和模块版本，预览后选择 `.leoapp.json` 文件位置。内置适配器不转换为此包。完成后点击应用管理的“确定”，再保存设置，以保留模块包身份；若丢弃设置，已明确导出的文件仍存在。
2. **导入**：先检查格式、协议、宿主范围、依赖、字段和体积；显示预览，再在本机编辑器中选择程序。包不能提供程序路径、参数、图标或管理员授权；默认普通权限。
3. **更新**：相同包身份且更高版本才可覆盖；原本机应用身份保留，原路径、参数、工作目录、图标、管理员选项及启停状态在编辑器中展示，由用户核对。取消任一窗口不修改当前模块。
4. **移除**：移除 Leo 中的启动能力，不删除本机软件；模块包的最后本机配置和入口偏好保留。再次导入相同身份的同版或新版包，可恢复原应用身份和配置，不必重建组合中的应用引用。
5. **保存**：上述安装/更新/移除先写草稿；应用管理“确定”后仍需设置“保存”才生效。现有设置原子写入成功后才替换宿主应用列表，继而刷新入口及取消失效请求。写入失败保留原配置；上一有效设置保存在本地 `.bak`。

移除后的包不单独占一个列表行；同身份重装通过已导出的包恢复。暂不增加包历史管理或永久清除个人配置按钮。原先未绑定模块包的普通本机应用仍沿用已有新建/编辑方式；其移除没有包归档。

## 包协议 v1

包只有一个 UTF-8 JSON 描述文件，没有目录解压、附带可执行文件或安装脚本。它是“调用宿主现有应用启动能力的公开描述”，不是应用安装器。

```json
{
  "Format": "LeoApplicationPackage",
  "Protocol": 1,
  "Id": "0123456789abcdef0123456789abcdef",
  "Version": "1.0.0",
  "Name": "示例播放器",
  "HostMin": "1.04.0",
  "HostMax": "1.99.99",
  "Dependencies": ["windows", "local-application/v1"]
}
```

| 字段 | 规则 |
| --- | --- |
| Format / Protocol | 固定格式与协议1；不和原 `LeoModule/1` 扩展混用 |
| Id | 32位小写 GUID，更新时保持；每台电脑映射到自己的应用 ID |
| Version | 三段非负整数；数值比较，`1.04.0` 和 `1.4.0` 等价；更新必须更高，已移除允许同版重装 |
| Name | 1～24字符，不含控制字符；公开名称可在导出预览中修改 |
| HostMin / HostMax | 包含两端的宿主程序集版本范围，导入时检查 |
| Dependencies | 只接受 Windows 与应用启动适配器v1；未知依赖拒绝，不下载依赖 |

拒绝未知、缺失、重复字段及不合法 JSON；最多64KB文件、16K字符、8层解析深度。身份不用于拼接目录或执行命令。此试点不承诺包来源签名或发布者认证。

## 生命周期和数据边界

- `ApplicationPackage` 是可分享描述；`InstalledApplicationPackage` 是仅本机的绑定记录。绑定记录保存在现有个人设置中，不随模块包导出；没有第二套配置文件事务或常驻服务。
- 安装/更新/移除均以克隆设置准备新快照，成功保存后应用。已有原子保存提供失败保留和前版备份；不是跨任意文件的事务框架。
- 已安装的包继续生成现有 `LocalApplicationModule`，复用 Q2 注册、统一执行器、停用/移除取消和配置代际检查；聊天、搜索、快捷按钮无需新增按包类型执行的分支。
- 移除后注册表不再提供对应动作，正在等待的请求沿用取消规则。已经由系统接受的应用启动无法撤销，Leo 不会杀掉用户程序。
- 包导出从白名单描述对象序列化，不序列化 Preferences、LocalApplication、Key、路径、图标、参数、管理员选项、历史或业务数据。公开名称由用户检查；名称中手动填写的个人内容不能由程序自动识别。
- 这是无网络、无脚本的数据型模块试点，没有新增后台轮询、自动下载或自动安装更新。
