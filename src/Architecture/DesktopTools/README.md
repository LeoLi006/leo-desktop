# 电脑状态与现有邮箱客户端：首批交付

日期：2026-10-21；运行基线00cb5c2。按用户修订后的便利优先范围开发，不实施原提案中的邮件同步/账户授权。

## 使用入口

设置 → 功能中新增“电脑状态”“邮箱客户端”，默认关闭，避免升级改变原布局/后台行为。勾选并保存后，搜索应用窗口的快捷栏/模块菜单提供入口；原入口显示设置可选择快捷栏、菜单或仅搜索。明确口令“电脑状态”“看看电脑状态”“打开任务管理器”“打开邮箱”共用QuickRouter及动作执行器，不调用模型。

电脑状态提供CPU、物理内存、系统盘剩余和网卡合计速率，及有限高占用进程，点击CPU/内存列排序。进程信息只读，不含命令行/完整路径，不提供结束进程或自动优化。CPU多核归一、网卡含虚拟接口，不能逐帧等同任务管理器或带宽测速。首采样/休眠/计数重置时不虚报为0；权限受限进程略过，界面明确只列可读项。

窗口可见时约2秒刷新聚合数据、约4秒更新进程、约30秒系统盘容量。关窗且未开提醒时停止采样。窗口中可选择后台提醒：约5秒聚合采样，不枚举进程；CPU≥90%或内存≥92%持续30秒才提醒，同类15分钟冷却，长采样中断重建持续判断。默认关闭，不进行长期指标落盘。资源异常不称为安全威胁；提醒可打开状态面板，继续由任务管理器处理。

火绒仅提供打开和手动配置EXE/LNK路径；只在已知安装位置被动查找，不读取私有日志、查杀结果或防护开关。路径无效时提示配置，不声称电脑安全/感染。

邮箱使用现有Foxmail/Thunderbird/经典Outlook或用户手动指定的EXE/LNK。有明确客户端时点击直接提交启动请求，没有或候选不唯一时进入配置；不先打开Leo收信中转窗。模块菜单另有“设置邮箱客户端”。QQ/Gmail网页版仅作手动备用入口，校园账户仍在客户端配置。不保存账号、密码、授权码，不读邮件，不同步未读，也不重复客户端通知。客户端本身能否登录各服务商取决于其支持及用户设置。

## 实现与模块化

[采样与生命周期](../../ComputerMonitoring.cs)：IComputerSampler、WindowsComputerSampler、ComputerMonitor、SustainedResourceAlert。Win32 GetSystemTimes/GlobalMemoryStatusEx及.NET网卡/进程/系统盘接口；后台Task采样，进程包装对象在finally释放。CPU差分、网络差分有休眠/计数回退保护；进程身份包含PID/启动时间，前次缓存有界于当前进程集合。

[注册与宿主](../../DesktopTools.cs)：system-monitor和mail-client以可选DesktopToolModule注册；复用现有契约、结构化空参数校验、贡献目录、真实渲染器与统一执行。动作未新增到LeoModule/1公开清单，不自动开放模型工具。窗口请求经现有ModuleWindowService投递并核对当前开关；新窗口有主题绑定与位置准备。邮件/火绒路径为私有偏好，模块/方案分享不包含路径。

[界面](../../DesktopToolForms.cs)：固定尺寸主题窗口，Esc沿既有窗口规则。采样使用OwnedActivityTimer登记所有者，取消/停用/退出后丢弃过期结果。窗口显示与后台提醒分开，异常只停对应活动，重新打开可显式重试。

新增偏好：SystemMonitorModule、DesktopMailModule、SystemMonitorAlerts（均默认false）及SecurityClientPath/MailClientPath。功能设置、保存/应用、方案捕获/准备和纯桌宠模板同步；原方案不含新开关时保持停用，原入口模式不变。极客模板可开启电脑状态，不会自动开启后台提醒。状态页明确客户端未配置/路径失效，不把模块注册当客户端已启动。

## 2026-10-21 定向修复与界面整理

- 比赛校时：旧路径把整份赛程缓存提交到上限125,000字符的清单动作。实际缓存规模为2,050场，足以使后台活动异常暂停。TodoClient仅挑选缺少比赛元数据的真实清单目标，去重后每16场提交；没有待补事项直接返回。保持原接口上限、提醒规则和持久化格式。FetchIds在模块停用/取消时传播取消，不吞为查询失败。
- 聊天：气泡按RichEdit实际字符位置测量高度；缩放后合并投递一次重排，避免在原生滚动布局尚未完成时留下旧宽度。预留滚动条空间，保留长气泡内部滚动。结果标签改为自动高度并随宽度重排，取消400像素截断。不变更模型、会话或读取权限。
- 图标：补齐media/notes及monitor/mail等绘制分支，两个新模块不再回退终端。BuiltinIcons提供18个稳定glyph:引用；应用编辑可从图标库选取或选本机图片。引用不含个人文件路径；图标采用已有矢量绘制体系，不新增位图依赖。
- 电脑状态：主题资源卡、CPU/内存占用条、进程隔行底色和排序标识，统一字号及留白，填满表头避免白色尾块。保留只读范围和原采样频率。

验证：桌面工具专项58项、聊天执行41项、后台任务44项，共143项通过，构建0警告0错误。包括超过上限的大缓存、空目标与旧比赛事项补齐、中英文多行气泡反复缩放、无横向溢出、本地结果超过400像素时完整重排、18个图标与选择器、进程两种排序、取消/退出与旧回调。界面截图只使用隔离数据。实际赛程网络可用性仍取决于数据源，本轮未联网查询，不将离线夹具称为远程校时成功。不打包、不上传GitHub。
