## 隔离方式

`--m05-todo-test <报告绝对路径>` 将夹具、备份和报告放在报告目录下；不同清单实例的损坏恢复夹具使用独立目录，避免共用备份。测试模型为本地工具调用夹具。真实 API 请求与外部客户端启动均为0，没有读取真实 Key 做收费验证。

原始报告留在忽略的 `.build/m05-todo/`；此目录只记录结果，不包含用户任务、配置路径或凭据。只检查本次改动及直接影响，没有执行全量产品测试。

安装仍使用固定本地安装脚本，替换前退出本仓库程序，比较个人 JSON 摘要；安装后再用隔离夹具验证并恢复正常运行。安装记录留在忽略目录，不制作发行包。
