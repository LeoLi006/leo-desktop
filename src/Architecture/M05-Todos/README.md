# M05 第三批：清单业务迁移

日期：2026-10-20。只迁移已存在的清单业务，保持界面、列表 JSON 和旧动作 ID，不改变发布版本。

## 调用路径

`TodoCapability` 注册清单动作，负责参数校验、请求回执、提交边界及模型能力描述。`TodoStore` 继续承担清单规则和原子文件保存；`TodoClient` 是窗口使用的同步适配器。宿主将操作派发到已有 UI 线程，避免另起写入队列与窗口线程争用同一份记录。

| 入口 | 进入方式 |
| --- | --- |
| 日历、日/周清单、右键、双击、拖动改期 | 共享 TodoClient → 注册能力 → TodoStore |
| 搜索、聊天、明确语音口令、组合 | 现有动作分发器 → 同一注册能力 |
| 自然输入 | 原确认窗口 → 确认后的统一新建操作 |
| 便签转待办、拖放新增 | 原标题确认 → 同一新建操作；便签带稳定来源身份 |
| 比赛加入清单 | Q4 比赛来源校验 → 清单桥接 → 同一数据服务 |
| 足球窗口与后台赛程同步 | 同一清单服务更新已有事项及提醒 |
| 到期扫描、提醒卡片、稍后提醒 | 同一查询、确认票据、完成及延后动作 |
| 免打扰、手动备份与恢复 | 同一服务；保留原设置与备份文件布局 |

窗口渲染、悬停摘要、比赛卡片按钮状态仍可读取本机不可变记录快照，不把每次绘制变成请求。重复规则查询、撤销可用性和备份文件列表也属于本机视图快照。业务写入和列表业务查询没有第二套窗口实现。独立预览窗口注册同一种能力，不回调旧业务分支。

## 动作与兼容

保留 `todos_open`、`todo_list`、`todo_add`、`todo_repeat`、`todo_complete`、`todo_complete_title`、`todo_edit`、`todo_move`、`todo_remind`、`todo_snooze`、`todo_postpone`、`todo_stop_repeat`、`todo_skip_repeat`、`todo_undo` 和 `todo_natural`。

结构化请求使用 `leo-action/1`：原 JSON 参数动作直接接收对应对象；原纯文本动作使用 `{ "value": "..." }`。协议、额外/重复字段、标题、日期、时间偏移、重复方式、真实事项及规则编号均由宿主校验。完成动作是“设为完成”，不会把重试变成反向切换。

内部动作覆盖快照、批量顺延、重要标记、删除/恢复、补齐重复事项、比赛写入/同步、到期查询/确认、免打扰、备份与恢复。这些动作不作为模型工具公开；`brain-*` 来源也不能直接调用内部动作。比赛桥接是宿主内部路径，保留外层请求调用链。

清单仍是原 `DailyTask` 列表，未新增必填字段、旁路数据库或个人数据迁移。稳定身份存入原有 Id 字段：新建请求及便签来源通过带命名空间的摘要产生事项/重复模板编号；旧编号原样保留。比赛仍通过持久 MatchId 去重，保留来源、时区、开赛及提醒管理字段。

## 提交、取消与重试

- 保存前检查取消；原子文件替换成功后才发布内存、撤销帧和变更事件。失败保留原文件、内存及撤销机会。
- 本机会话保留最多256份写入回执。同一请求编号和相同内容重试返回原结果；同编号不同内容拒绝执行。新建与便签转换的身份还能跨重启阻止重复生成。历史回执不宣称后续未被用户编辑或撤销。
- 保存完成的回执先于变更通知发布。分发器只接受模块提供的提交证据；取消发生在已提交操作之后，仍报告已保存，不错误提示未执行。排队取消不会稍后写入；取消处于文件替换进行中而尚无提交证据时，保守提示核对状态，原身份可供重试。
- 多次提醒扫描复用原计时器，不建立第二个调度器。确认票据同时包含事项编号、原提醒时间及稍后提醒时间，过期票据不能吞掉新的提醒。完成/改期/提醒设置都会从同一服务重新读取最新记录。
- 通知使用原有稳定唯一键；提醒标记写入失败时保留重试资格，进程内已展示的同一提醒不会反复弹窗。重复事项统一设置提醒时清除旧稍后提醒状态。
- 免打扰保存采用同一原子写入，预览使用内存配置，隔离测试只使用夹具目录。

## 大脑边界

注册表公开清单查询、打开、新建、重复新建、完成、标题编辑、改期、提醒与跳过本次重复。只有用户本轮明确提出清单/待办读取请求，才能返回清单；一般“计划旅行”不构成读取私人事项的同意，否定读取请求也会阻止查询。

模型修改必须使用本轮实际返回的事项编号；多个目标含糊时先澄清。预览使用真实事项标题和目标日期/时间，原有最多4步、确认、取消与 Q4 执行规则继续有效。清单在预览后发生变化会使旧计划失效，要求重新查询/预览。记录正文仅在显式查询结果中提供，不进入通用诊断历史；完整快照、备份路径和内部提醒票据不提供给模型。
