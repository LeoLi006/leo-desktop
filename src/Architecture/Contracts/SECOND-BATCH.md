## 真实输入边界

| 边界 | protocol / adapter / encoding | 行为 |
| --- | --- | --- |
| 现有结构化动作 | leo-action/1 / module-adapter / object或value-wrapper | 保留原适配字段、参数校验与模型确认 |
| 本机应用 | leo-action/1 / application-adapter / object | 沿用第一批应用编号归一 |
| 聊天语音内部动作 | ActionRequest / host-private / private-handle | 仅宿主已有会话/任务票据；外部结构化调用全部拒绝。chat_open例外，仍只接受空对象 |
| 现有组合 | ActionRequest / legacy-only / legacy-value | 组合尚无外部结构化适配器，保留名称和恢复JSON文字，不伪装成应用适配器 |

`IContractInputBoundary` 只把原输入边界用于描述校验。Conversation的实际Adapt复用同一“仅chat_open接受外部结构化请求”判断，未放宽任何动作。该接口不是授权机制；真正的适配器、分发器及Q5仍决定能否调用。

契约允许原有session效果及completed、released、cached、steps-completed证据，以表达现有执行，不重命名结果或修改进程外协议。completed表示当前回复工作结束；steps-completed不证明每个外部客户端已达到期望业务状态。

## 七类描述与被动依赖

| 类别 | 参数与结果 | 读取依赖时的边界 |
| --- | --- | --- |
| 便签 | text、id、scope、value、task沿用原适配；记录/列表为私有，保存仍有原回放与原子保护 | note-store为unknown，不调用惰性store工厂、不加载正文 |
| 代理 | 空对象；继续启动→等待→执行→核验，未知状态不假称成功 | 客户端为unknown，不调用available或读取/切换系统代理 |
| 音乐 | query/id/direction及空参数；实际候选与控制回执，accepted不等于已播放 | 网络和客户端为unknown；已有候选/历史只用于ready/unknown布尔观察，不导出歌名 |
| 剪贴板 | query/text/id/enabled沿用原校验；正文及记录编号均私有 | 仅读已存在服务的关闭标志和History.Error有无，不读Windows剪贴板。关闭历史记录不禁用保存的收藏或窗口能力 |
| 聊天语音 | 私有会话/任务票据；voice_accept含会话和识别代次，正文、Key、音频留在原有有界任务 | 只读ConversationHost关闭标志；模型接口与输入/输出语音依赖保持unknown，不加载Key、设备或ASR |
| 比赛安排 | 原MatchReference或旧字符串编号；cached引用与committed事项回执 | 比赛来源保持unknown，不调用缓存来源工厂；清单只观察已有Error状态 |
| 组合 | 名称、旧别名或恢复JSON文字；原步骤结果与恢复规则 | 所选能力及日志为unknown，不打开组合配置、日志或调用执行委托 |

unknown表示本次描述读取没有探测，不等于缺失或禁止执行。依赖观察不成为新前置拦截器，原路径准备、缓存回退、停用、代次核验与恢复确认全部保持。
