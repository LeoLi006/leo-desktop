# C04-G2：普通模块与入口联合试点

日期：2026-10-21。本批复用[限定服务样例](SCOPED-NOTES.md)，只验收贡献数据、注册及执行闭环，不给真实界面新增入口。

## 实际缺口与最小接入点

既有EntryContributions从本机应用配置或固定内置列表生成，普通注册模块无法只凭自己的描述提供入口。本批新增可选IModuleEntryContributor.DescribeEntries，返回既有EntryContribution数组；不扩展LeoModule/1，不添加控件、委托、可执行内容或新的业务开关。

CapabilityRegistry.Register接受实现契约的可选贡献模块；不允许贡献模块替换内置模块/已有宿主动作。原应用和内置注册路径保留。原注册与新移除共用Remaining方法计算兼容快照，没有复制执行策略。

ModuleEntryContributions.Read从同一实际注册表获取贡献，先校验再投影。新模块不必在这个目录增加业务名称分支。快照提供Entries、Buttons、Menu、Search四个数组，后三者是数据投影，尚未绑定真实Launcher、右键菜单和快捷栏渲染器。这一点是本轮剩余边界，不能据此宣称新模块已自动显示UI。

## 描述与校验

- Id必须以本模块Id加斜杠开头；Target固定为leo-module-entry:加完整入口Id，不是程序或文件路径。
- Editor固定module-action；Parameters是主动作的JSON对象，菜单子动作复用EntryMenuAction.Value中的JSON对象。Parameters默认{}，不改变旧入口的字符串参数处理。
- 主动作及所有菜单动作必须属于实际注册模块；没有跨模块转接豁免。普通模块不能借Edge旧适配规则请求其他模块动作。
- 每模块至多32条入口、每入口至多16个菜单动作、24个简称；重复入口或畸形描述隔离该提供者，不移除其他模块的贡献。依赖仍由原能力执行时校验，不将Dependency字段当执行许可。
- 宿主现有EntryDisplayModes覆盖本入口的缺省显示方式。搜索专用只隐藏按钮/菜单，不停用能力；模块停用移除全部可用投影。顺序沿描述与注册表顺序，旧图标/排序来源未改。

数组复制避免修改快照改写提供者；每次读取重新获取当前状态。目录不写Preferences、不探测客户端、不执行模块动作、不向模型发送Parameters。没有新常驻计时器。

## 统一点击与移除

ModuleEntryContributions.Execute只接受入口身份、来源、可选菜单序号及取消令牌。它重新读取/核验当前描述，再交给原ExecuteStructuredAsync；不执行调用者缓存的Target或参数。能力仍做真实参数、依赖和数据校验，沿用原失败、取消、结果及私有数据规则。

CapabilityRegistry.Unregister仅接受当前已注册贡献模块的同一实例；错误实例不移除，重复移除返回false。先构造下一兼容快照再替换状态。模块退出后的旧入口不能退化为路径启动。

Unregister本身只改注册表。宿主还须调用ActionDispatcher.CancelDisabled取消在途工作，并明确Dispose自己拥有的服务；不以移除注册等同已经撤销外部操作或释放所有资源。测试覆盖移除后取消等待中的查询。服务和数据保留规则不由入口目录改写。

## 编译接入样例

ScopedNotesExampleModule在原限定服务构造不变的基础上，实现可选贡献接口，声明一个只读便签查询入口。按钮、菜单和搜索三个投影使用同一动作与参数；显式测试注册后即可读取和执行，不需要新的集中业务分支。

生产宿主不注册该样例，也未调用新目录渲染真实界面，所以用户不会看到新增示例按钮或搜索项。无UI模块的模型能力仍需另行声明，本批不自动将入口当作模型工具。内部可信对象的贡献不是任意代码包加载或安全沙箱。
