# R06：普通模块入口故障诊断

日期：2026-10-21；核对基线f269c25。只补现有目录隔离状态与运行检查的连接，不改变模块执行策略、权限或界面入口。

## 当前状态与计数单位

ModuleEntrySnapshot新增Diagnostics，读取既有贡献目录的同一轮遍历顺带生成：

- Available：成功校验且启用的入口条数，隐藏按钮或仅搜索仍计为可用。
- Disabled：成功校验但入口/模块停用的入口条数。
- Isolated：描述获取、参数或归属校验失败而整组隔离的提供者数量；无法可靠获知其入口条数，因此不与旧“异常入口”数量相加。
- Faults：当前隔离提供者的模块标识与错误类型，去重并最多64条。总隔离数量不因明细截断而减少。

停用但描述本身错误的提供者计入隔离，不伪造为已知停用入口。一个提供者错误不会清空其他提供者的有效贡献。

HostServiceDiagnostics读取目录一次取得这些数量；现有运行检查摘要新增“普通模块入口：可用 / 停用 / 隔离模块”一行，只显示数量。没有提供者时为零，窗口/宿主关闭后不重新调用提供者。

## 无历史累积与隐私

诊断属于本次读取快照，不建立全局故障缓存、不写文件、不订阅事件或增加轮询。重复读取不会追加历史记录；再次检查时，已恢复或移除的提供者不再显示为当前隔离。已被调用者持有的旧快照仍代表其读取时状态。

不调用FeatureFaults.Report或OperationFeedback，不弹窗、不生成通知。明细不存异常消息、堆栈、入口名称、别名、路径、业务参数或正文。模块标识限100字符ASCII字母数字及冒号/下划线/连字符，异常标识替换为固定占位；错误类型限80字符ASCII类型名，异常类型名使用固定占位。记录不是任意不可信代码的安全沙箱。

## 验证与交付
