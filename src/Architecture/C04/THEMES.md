# C04：主题服务最小试点

## 边界与资源

UiTheme继续由宿主管理当前皮肤与配置；Snapshot提供不可变值记录，包含版本、品牌文字、语义颜色、圆角、透明度、字体规格和逻辑尺度。快照不携带用户配置、控件、位图或Font。逻辑尺度1表示原布局单位，实际DPI缩放由WinForms负责，宠物大小滑动条不改变窗口比例。

ModuleThemeBinding是音乐、媒体窗口使用的主题服务适配器。它读取快照并订阅宿主变化；窗口只负责绑定的生命周期。颜色仍由UiTheme的原始色映射器应用，避免另一套算法造成重复染色；自绘控件继续读取相同宿主令牌。窗口原有字体、尺寸、配置格式保持不变，不在换肤时反复创建字体。新控件的字体仍由创建者负责，快照字体规格不能被当作共享Font资源。

## 接入格式

```csharp
// 所有子控件添加完毕后，在UI线程创建。
theme = new ModuleThemeBinding(this);
// 窗口Dispose(bool)中，先于base.Dispose调用；可以重复调用。
theme.Dispose();
```

MusicForm和MediaForm就是编译接入样例。绑定初始化捕获控件原始色；主题全局刷新跳过这些窗口，避免重复遍历。原有ControlAdded适配继续处理动态歌曲行。未迁移窗口保持原全局路径，原UiTheme.Attach兼容入口不删除。

## 投递与释放

可见时订阅并同步读取最新快照。隐藏时退订并取消本订阅在途通知，重新显示创建新订阅；MusicForm的关闭即隐藏因此也会退订。窗体销毁时解除事件和弱表登记。宿主静态事件不会持有隐藏/已销毁的试点窗口。

通知通过已有ModuleWindowService投递UI线程；执行前检查窗口生命周期、取消令牌、通知代次和主题版本。快速换肤只允许最新版本写回。每次订阅捕获自己的令牌，即使旧事件委托已被发布者取出，重新打开后也不能借用新订阅。服务无轮询计时器、不启动外部应用。单个订阅异常使用原FeatureFaults隔离，不阻断其他订阅。

## 定向验证

锁定构建后运行 `--theme-service-test <隔离报告绝对路径>`。12项检查覆盖两窗订阅、值快照、旧映射一致、字体和尺寸不变、排队旧版本、隐藏取消、重新打开、旧订阅重入、关闭释放及30轮短测。另运行客户端46项、音乐剪贴板54项确认直接相关兼容行为。报告仅位于忽略的.build目录，不读取真实Key或启动客户端。

短测只检查绑定释放和普通资源变化，不把短期内存变化当作长期性能结论。本轮没有迁移其余窗口、字体存量资源或整个绘制系统，完整主题服务仍保留后续审批范围。
