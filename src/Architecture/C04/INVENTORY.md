# C04 已接入宿主服务清册与收尾

## 当前服务归属

本清册对应已运行的最小服务，不是完整C04完成声明。接口仍是宿主内部约定，未发布新的外部代码模块协议。

| 服务类型 | 实现/格式 | 已接入范围 | 创建与释放归属 |
| --- | --- | --- | --- |
| 应用配置及依赖 | IApplicationHostServices / leo-host-application/1 | 自定义本机应用，只读本应用配置及文件依赖 | 注册表按应用构建；随该配置代次被替换，不新建线程或计时器。 |
| 客户端配置及依赖 | IClientHostServices / leo-host-client/1 | Clash、音乐、媒体的启用状态、配置哈希与原被动摘要 | 正式宿主构建，注册表替换对应能力；原客户端资源队列继续由宿主持有。 |
| 内存故障记录 | ApplicationHostFaults | 应用与客户端两组记录器，分别最多128条 | 注册表持有；只保存模块、阶段、异常类型，不落个人文件。 |
| 固定窗口及反馈 | ModulePresentationService / leo-host-presentation/1 | 应用、足球、音乐、媒体、清单、便签、速记、聊天、剪贴板九目标 | PetForm创建并在退出清理开始时关闭；待请求退出后释放取消源。 |
| 窗口端口 | IModuleWindowPort | 模块只能请求已绑定目标 | 轻量端口，不拥有Form或整个宿主，主服务关闭后不能复活。 |
| 进度租约 | ModuleProgressLease | 音乐、媒体现有队列 | 每个操作创建，结束后只清理匹配提示，旧进度不再显示。 |
| 服务诊断 | HostServiceDiagnostics | 已接入配置/依赖作用域、窗口状态、在途请求、异常入口、故障阶段数量 | 按Preferences弱关联；关闭态停止读取注册表或已销毁服务。 |

## 运行检查的摘要边界

“配置/依赖作用域”统计已接入的自定义应用和三类客户端，不把停用误作异常，也不声称所有内置模块已经迁移。窗口可用数量依据现有启用或存活状态。

在途窗口及反馈包括已排队但未完成的UI投递，结束、取消、显示异常或宿主销毁均归还计数。异常入口数量覆盖C05已接入的六类内置入口和自定义应用：重复或畸形定义、动作缺失或归属错误计入；仅隐藏或正常停用不计入。

摘要只输出固定服务类型、状态及数字。故障按配置/依赖/执行三个阶段聚合，不显示异常原文或类名，更不显示应用ID、名称、路径、Key、会话、剪贴板或便签正文。读取摘要不启动客户端、不枚举语音设备、不发网络请求或执行动作。已有运行检查其他项目的行为不在本批改动范围。

## 仍需保留的兼容适配

| 适配 | 保留原因 |
| --- | --- |
| ModuleWindowService.ShowAsync(Action, token) | 清单及剪贴板本地数据事务、会话内部语音UI调用仍需要原UI调度；不是固定窗口端口的可删除副本。 |
| 能力构造中的旧show委托与可选窗口参数 | 原独立窗口与既有测试仍使用；正式宿主已绑定固定端口，不能同时删除兼容构造。 |
| 应用/客户端服务的旧委托构造 | 旧调用由默认限定服务适配，未改变启动或客户端执行策略。 |
| ModuleJsonData和现有业务Store | 便签原子保存、清单与其他业务数据仍由原服务处理；本批不迁移全部存储。 |
| 未接入的反馈与窗口 | Clash和其他工具仍沿用已授权的原适配；不能据此删除其调用。 |

旧ModuleFeedbackService已无生产调用，仅有一个直接镜像测试。本批删除该类型和旧镜像检查；成功静默、失败提示继续由现有统一反馈专项验证。Q3历史说明已指向现用服务。

## 退出修复

核对确认：原统一窗口服务要等控件销毁或排队回调再次执行才结束部分等待，退出清理期间存在空档。

现由PetForm在ReleaseResources开始时关闭统一窗口服务。服务先阻止新请求、使所有目标代次失效，再在锁外取消自身在途投递。链接取消源逐个释放；宿主取消源在取消回调完成且所有计数归零后释放。重复关闭安全，旧反馈及提示清理不会复活服务，也不会阻塞其他清理步骤。

单个窗口回调失败仍只影响本请求。已经提交的数据、提醒和业务任务的取消/确认规则继续由原执行器负责，本批没有把窗口关闭等同于数据回滚。

## 定向验证

锁定构建零警告。收尾专项22项及直接相关226项通过：窗口/反馈104项、便签44项、聊天语音41项、提醒宿主37项，共248项。便签数量由45变44是删除上述过渡类型的镜像检查，不是业务验证失败。

覆盖控件存活时主动取消、锁外取消、在途计数及取消源释放、退出后拒绝新请求、重复关闭、真实宿主提前清理、错误入口计数、停用/隐藏非故障、诊断脱敏与实际运行检查挂接。

30轮排队→退出短测的在途计数均归零；资源读数保存于忽略的构建报告，不使用苛刻阈值或据短测宣称长期性能结论。只使用模拟会话与隔离数据，不调用真实Key、麦克风、真实剪贴板正文或外部客户端。不制作发布包、不上传GitHub。
