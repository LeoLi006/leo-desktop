# Leo v38 · 静默点歌与原生歌词

启动 LeoLauncher.exe，保留整个文件夹。需要 Windows 与 .NET 9 Desktop Runtime。

- 右键主菜单仅保留「每日清单」「音乐」「退出 Leo」。鼠标悬停「音乐」展开置顶歌单、「随手听」和「显示 / 隐藏歌词」。删除多余的应用搜索项，点击Leo仍可打开应用搜索。
- 点歌改为直接向已运行的QQ音乐专用后台窗口发送原生命令，并附加已验证的 silent 标志。不再通过启动QQMusic.exe点歌，不会先弹出主界面。未运行QQ音乐时会提示启动，可从随手听的「打开QQ音乐」启动。
- Ctrl+Alt+L 切换QQ音乐自己的桌面歌词，右键「音乐」里和随手听「词」按钮也可切换。使用原生歌词窗口和客户端自己的歌词能力；没有下载、另行缓存歌词或调用模型API。
- 原生歌词转发已验证本机QQ音乐21.21；QQ客户端更新为其他版本时会停止使用旧版窗口定位，以免控制错误窗口。需要保留QQ设置中默认的Ctrl+Alt+W歌词热键绑定。Leo新快捷键被其他软件占用时，会提示使用菜单。
- 托盘改为蓝红金色盾牌、L与足球图标；可执行文件也嵌入同一套多分辨率图标。
- 保留v37的同步歌单、语音本地口令、清单、免打扰和自动备份。

验证：新增7项自动检查通过，实际QQ静默切歌观察到主窗口显示/前台激活事件均为0；原生歌词开关来回切换并恢复成功。此前v35/v36/v37、清单、快捷指令和窗口回归检查通过。报告为 *test.json 与 qq-native-live38.json。

source 提供可复查源码与图标。临时二进制检查工具未随应用打包；产品仅使用Windows消息接口调用已安装的QQ音乐。
