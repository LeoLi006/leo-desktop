# Leo · 巴萨主题桌面伙伴

把应用启动、每日计划、足球赛程、快速点歌和语音操作放在一个桌面入口里。

Leo 是运行在 **Windows x64** 上的独立桌面应用。常用操作优先在本地完成；需要自然语言理解时，再通过用户自行配置的兼容 API 调用模型。

**当前版本：v0.49.1** · [完整使用说明](src/USER_GUIDE.md) · [第三方许可证](licenses/) · [球队标识来源](assets/badges/SOURCES.md)

> 仓库提供源码、素材和固定版本依赖；[Releases](https://github.com/LeoLi006/leo-desktop/releases/latest) 提供不含个人数据的 Windows 安装包。模型功能需要自行配置服务和密钥。

### 当前版本重点

- **自选皮肤**：默认巴萨，可选阿根廷、西班牙、迈阿密国际、曼城；覆盖全部动作，独立于足球模块，不再随比赛自动换装。
- **完整四向吸附**：原始站立帧衔接八张起步姿态，再进入收起动作；右侧视线统一朝屏幕内侧。半隐藏保留耳朵与羊角，悬停展开，也可直接拖出。
- **清晰显示**：半透明轮廓保留抗锯齿；各队真实款式的球衣纹样、队徽和短裤搭配，先贴合动作再缩放。

- **日常维护**：通知收纳、临时专注、剪贴板保护、手动检查更新及无需开发环境的 Windows 发布包。

## 桌面上的操作方式

**单击 Leo** 打开应用搜索，再点一次收起。搜索打开时锁定 Leo 的位置，关闭后可拖动。

- 脚下常驻：**聊天、清单、下拉键**。
- 下拉区：已启用的 **管理员终端、Clash、Edge 搜索**。
- 应用搜索窗口上方：**足球、QQ 音乐**，音乐入口位于足球按钮旁边。
- 右键 Leo：皮肤、设置、清单、音乐、自定义组合、通知、临时专注和退出。
- 悬停 Leo：查看未完成事项及下一场关注比赛摘要。
- Esc：关闭当前功能窗口或收起面板，不会直接退出桌宠。

拖近屏幕左、右、上、下边缘并松手，会先播放该方向的起步过渡，再进入收起动画，进入只露头部的半隐藏状态，脚下按钮同时消失。头部、耳朵、羊角保持完整显示。

- **悬停展开**：鼠标移到露出的头部，动画倒序播放；恢复完整体型后，按钮再出现。
- **直接拖出**：按住露出的头部拖向屏幕内部，松手后回到正常待机；不需要先等展开结束。
- **仅点击头部**：只唤醒，不会同时打开搜索；展开后再次点击可使用搜索。
- **重新停靠**：再次拖近边缘松手；在设置 → 功能中可关闭边缘停靠。

底部按可用工作区定位，避开任务栏。游戏或视频全屏时可自动隐藏，退出全屏后恢复。

## 应用搜索与剪贴板

搜索结果最多两排，每排七个图标。支持完整名称、拼音及常见简称，例如 `wx`、`weixin`、`vsc`；可右键图标设置自己的简称。

收藏应用置顶显示，无搜索文字时可以拖动排序。没有输入时还会显示最近使用的应用；历史记忆和上下文排序可以在设置中关闭。

支持方向键选择、Tab 切换、Enter 打开、Shift+F10 打开所选应用菜单、Ctrl+L 返回输入框。文字编辑与结果导航区分处理。

输入“剪贴板”或“剪切板”打开历史。普通历史最多 50 条，收藏单独保留并设有容量限制；清空普通历史不会删除收藏。记录只保存在本机。

## 清单、重复事项与提醒

通过日历安排未来日期，切换每日或每周视图；过去未完成的事项单独放在“逾期”中。

- 单次、每天重复、每周重复。
- 双击改标题，拖到日历日期上改期，提醒时间随日期移动。
- 右键快速完成、移到明天、选择日期、设置提醒、删除或撤销。
- 重复事项可仅修改或跳过本次，不影响后续安排。
- 一键顺延未完成事项；支持本次运行内最近 20 步清单撤销。
- 提醒可稍后 10 分钟或 1 小时；支持免打扰时段。
- 清单变更更新最新备份，提供每日留档、手动备份和恢复。

**提醒依赖 Leo 保持运行。** 关机或退出期间不会响铃，重新启动后会补报符合条件的提醒；免打扰及全屏隐藏期间暂缓弹窗。

## 足球与音乐

### 足球

默认关注 **巴塞罗那、曼城、迈阿密国际**，可在“管理关注”中修改。目录包含97支俱乐部和55支国家队，共152支球队，支持联赛筛选、中文名、简称和英文名搜索，最多关注 24 支，保存后跨重启保留。查看关注及焦点比赛、近期已结束的比赛、俱乐部近期赛程和所在联赛积分榜，详情在同一窗口切换。

已确定时间且尚未开赛的比赛可加入清单，默认提前 10 分钟提醒；关联赛程的变化可同步到对应安排。当天的下一场关注比赛在悬停摘要中显示倒计时。

可保存四个观赛网址，开启 Edge 模块后点击打开。Leo 不提供比赛视频资源。赛程通过 ESPN 等专用数据接口读取，失败时可能使用缓存；比赛时间按本机时区显示。

### QQ 音乐

音乐定位为**快速点一首歌**。输入歌名或歌手，点击候选发送给 QQ 音乐；客户端未运行时尝试先启动，再发送播放请求。

支持最近歌曲、播放或暂停、上一首、下一首及桌面歌词快捷控制。歌单请在 QQ 音乐客户端操作，Leo 不维护或同步歌单。登录、会员权限和歌曲可播放性由 QQ 音乐处理，歌词控制还依赖兼容的客户端快捷键设置。

## 模型、本地语音与联网的分工

聊天主要用于理解简短指令、协调现有功能，以及随手问一句。复杂自然语言任务可通过工具调用打开应用、处理清单、查询赛程或执行其他已提供的动作。

| 操作 | 是否需要模型 API |
| --- | --- |
| 应用搜索、剪贴板、清单、提醒、设置 | 不需要 |
| 明确的本地快捷指令、自定义组合 | 不需要 |
| SenseVoice 语音转文字 | 不需要，在本机识别 |
| 足球更新、歌曲搜索 | 需要联网，使用专门数据源，不等于调用模型 |
| 网页搜索 | 打开浏览器搜索，不通过模型代查 |
| 自由聊天、复杂意图理解和任务拆解 | 可能需要，使用自行配置的模型服务 |

支持 Chat Completions 和 Responses 两种兼容接口，可填写 Base URL、模型名称和 Key，或尝试读取服务提供的模型列表。不同中转站对流式回复、工具调用和用量参数的支持可能不同。

默认每天最多 100 次模型生成请求，可修改，0 表示不限。多轮工具回复按实际请求次数计算；已发出的失败或取消请求也计入限额。Token 只累计服务实际返回值，缺失时标为未报告，不估算费用。达到限额后本地功能仍可使用。

本地识别后的文字如果进入模型对话，会发送给所配置的服务。Leo 没有通用网页浏览能力，不会自动核验所有模型回答中的实时信息。

## 安装与运行

### 直接安装（推荐）

从 [最新正式版本](https://github.com/LeoLi006/leo-desktop/releases/latest) 下载 `Leo-v0.49.1-win-x64.zip`，完整解压后运行 `Install-Leo.cmd`，选择 Leo 专用目录。包内包含 Windows 桌面运行时，无需先安装开发环境；首次启动按需选择模块。

更新时选择原目录，按安装器提示备份和更新。个人配置、清单、模型不随发布包提供；备份与回退详见[使用说明](src/USER_GUIDE.md)。同页 `.sha256` 文件可用于校验下载是否完整。

### 源码构建环境要求

- Windows x64、PowerShell、.NET SDK 9；具体 SDK 版本与滚动策略见 [global.json](global.json)。
- 从 GitHub 获取源码时需要 Git。
- 语音需要麦克风和另行安装的 SenseVoice 模型。
- QQ 音乐、Clash Verge、Edge 等功能需要相应软件，均可在设置中停用。

### 从源码构建

在仓库目录执行：

```powershell
./scripts/Build.ps1 -Locked
./scripts/Test.ps1
./scripts/Install-Local.ps1
./scripts/Install-VoiceModel.ps1
./scripts/Start.ps1
```

构建校验固定依赖及锁文件，依赖原包与 SHA-256 清单位于 `vendor`。首次准备 SDK 和语音模型可能需要联网；已有语音模型会先校验。模型体积较大，不包含在 Git 仓库中。只使用文字与本地启动功能时，可暂不安装语音模型。

构建产物在 `.build/Release`，正式运行目录固定为 `app`。后续更新仍安装到同一目录，保留个人 JSON 配置和模型，无需复制完整版本文件夹。

Clash 系统代理切换在后台操作，不恢复或激活客户端窗口。由 Leo 启动未运行的 Clash 时，会先启用客户端原生静默启动选项；配置与订阅内容保持不变，唯独 `enable_silent_start` 置为 `true`。

### 首次设置

1. 运行 Leo，等待本机应用索引完成。
2. 右键进入设置，调整大小、快捷键、全屏隐藏及需要的模块。
3. 软件无法自动检测时，在 **功能 → 软件路径** 中选择程序；留空恢复自动检测。
4. 需要模型功能时再填写 API 配置，其他本地功能无需先填写 Key。
5. 在 **运行检查** 中检查启动项、快捷键、客户端路径和语音模型。API 连接检测需手动点击。

## 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+Space | 打开或收起应用搜索 |
| Ctrl+Alt+V | 打开聊天并直接语音输入 |
| Ctrl+Alt+L | 显示或隐藏 QQ 桌面歌词 |
| Esc | 关闭当前功能窗口或收起面板 |
| Ctrl+Z | 在清单输入框外撤销最近一次清单修改 |

快捷键可以修改或停用，歌词快捷键随音乐模块停用。QQ 歌词控制需要客户端保留兼容的歌词绑定，冲突时可通过设置调整。

## 配置迁移与恢复

在 **设置 → 常规 → 配置迁移与恢复** 中导出 `.leo.json`，可包含清单、重复规则和提醒。

迁移内容包括收藏、简称、快捷键、模块开关与路径、自定义组合、球队关注、观赛网址、免打扰时段和 API 限额。导入前显示摘要并自动备份，再替换文件中包含的配置；不包含清单时保留本机清单。可恢复到上次导入前的状态。

换电脑时尝试按应用身份重新匹配收藏、简称和组合中的应用。无法唯一匹配或路径失效时会提示处理，不会自动启动这些程序。开机启动和窗口位置沿用目标电脑设置。

**导出文件属于个人文件**：可能包含清单、网址、简称和软件路径，请自行保管，不要提交到源码仓库。导出不包含 API 配置及 Key、聊天、剪贴板、使用历史或语音模型。

## 隐私与数据存放

- 个人配置、聊天、清单、剪贴板、使用记录及缓存保存在本机运行目录。
- API Key 使用 Windows 当前用户的 DPAPI 加密保存，不是跨电脑可直接使用的明文配置。
- 基础功能不要求模型服务；使用模型或专用联网功能时，会向对应服务发送必要请求。
- 仓库忽略运行目录、个人 JSON、备份、模型和构建缓存；推送前仍应检查跟踪清单与提交历史。
- 请勿在 Issue、截图、日志或配置样例中贴出密钥、个人路径、剪贴板、待办和私人观赛网址。
- GitHub 公开的是经过检查的源码与项目素材；公开仓库不等于分享运行目录。程序不会自动发布个人配置。

## 常见问题与已知边界

- **应用搜索结果不全**：首次索引可能尚未完成；可尝试完整名称或设置简称。
- **开机没有出现 Leo**：检查 Windows 启动应用状态与 Leo 运行检查，必要时修复启动项，再重新登录验证。
- **收不到提醒**：确认程序正在运行，并检查时间、免打扰和全屏隐藏状态。
- **语音无文字**：检查模型文件、默认麦克风、输入设备和录音音量。
- **QQ 音乐没有播放**：检查客户端状态、登录和歌曲权限；客户端版本变化可能影响控制能力。
- **Clash 或浏览器未找到**：手动选择程序路径，并确认模块已启用。
- **赛程或歌曲查询失败**：外部接口可能变化、限流或不可达；赛程可能保留旧缓存。
- **接口不能流式回复或调用工具**：检查模型和中转站能力；不支持用量参数时可关闭请求 Token 统计。
- 聊天支持缩放，部分功能窗口采用固定大小保持稳定，并非所有窗口都可任意拉伸。

详细操作与排查见 [使用说明书](src/USER_GUIDE.md)。反馈问题时请提供版本、复现步骤和已脱敏的信息。
