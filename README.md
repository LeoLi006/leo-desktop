# Leo · 可按需配置的桌面伙伴

**简体中文** | [English](README.en.md)

让应用、待办、便签、足球和常用操作更容易找到，也能把多个操作组合起来。想只用桌宠也可以，不用把所有功能都打开。

**Windows x64 · 最新发布v1.05.0 · 本地功能无需模型API。**

[下载安装](https://github.com/LeoLi006/leo-desktop/releases/tag/v1.05.0) · **[三分钟快速上手](src/QUICK_START.md)** · [功能入口速查](src/QUICK_START.md#我想做什么入口速查) · [常见问题](src/QUICK_START.md#遇到问题先看这里)

## 第一次用，先做这四步

1. 下载`Leo-v1.05.0-win-x64.zip`，完整解压，运行`Install-Leo.cmd`。
2. 单击桌面小羊，输入软件名，点击结果或回车打开；再点小羊关闭搜索。
3. 点脚下清单图标，记一件待办；或者右键→清单与记录→一句话速记。
4. 右键→设置：常规改名字、大小和开机启动；功能页只开启需要的工具，最后点“保存设置”。

不需要先理解模块、接口或实现。聊天API、语音模型和第三方软件都按需配置。

## 不知道功能在哪里？

| 入口 | 可以找到什么 |
| --- | --- |
| **单击小羊** | 应用搜索、文件/文件夹路径、剪贴板入口、顶部快捷栏 |
| **脚下聊天 / 清单 / 展开工具** | 聊天、待办，以及已开启的终端、Clash、Edge搜索 |
| **右键→清单与记录** | 每日/每周清单、速记、便签、通知记录、专注 |
| **右键→应用与媒体** | 应用、聊天、音乐和媒体；其他可选功能也可在这里找 |
| **右键→组合动作 / 外观** | 一次做多件事、切皮肤和主题编辑 |
| **右键→设置** | 开关功能、程序路径、图标、语言、快捷键、备份和运行检查 |

**功能开着但看不到按钮？** 到设置→功能→入口显示检查；它可能被放到了菜单或仅搜索。页面底部按钮需要向下滚动才能看到，改完还要保存设置。

## 按自己的需要使用

- **只想养桌宠**：调整名字、大小和皮肤，使用吸附/悬停展开，关闭不需要的工具。
- **整理桌面**：应用搜索、收藏和简称；输入路径打开文件，添加自己的软件快捷按钮。
- **随手记事**：日/周/日历清单、重复与提醒；一句话便签，之后可转待办。
- **看球和听歌**：关注球队、赛程与积分榜、观赛网址、QQ音乐单曲点播和媒体控制。
- **少做重复操作**：用现有组合动作串起常用步骤，明确操作优先本地完成。
- **需要时再加**：电脑状态、已有邮箱客户端入口、模型聊天和本地语音。

Leo不会替代专业软件：邮件在原客户端处理，音乐和媒体依赖对应应用；火绒仅快速打开。自由聊天需要自配API，语音需单独准备SenseVoice模型。足球/歌曲查询需要各自的网络来源。

## 更新与反馈

更新时选择原来的Leo安装文件夹，先保留私有备份；发布页提供SHA-256校验文件。安装包包含Windows桌面运行时，不含个人配置、API Key、语音模型或第三方客户端。

出问题先到设置→运行检查，再看[常见问题](src/QUICK_START.md#遇到问题先看这里)。仍未解决可[提交Issue](https://github.com/LeoLi006/leo-desktop/issues)，附版本、复现步骤和脱敏截图，不要上传Key或整个运行文件夹。
